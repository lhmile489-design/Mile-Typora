架构说明

Mile Typora 是一个只读的本地 Markdown 阅读器。一个进程管理多个原生窗口，每个窗口维护自己的阅读上下文，文件变更事件按窗口精确投递。更多背景见 产品需求文档 与 mygo 官方文档。

只读即只读：P0 阶段不修改源文件的任何字节，也不在工作区写入元数据。

分层

  • Go 原生层：系统对话框、窗口生命周期、路径授权、目录扫描与变更监听。
  • 绑定传输层：类型化请求响应，使用 EmitPage 按页面定向推送。
  • React 界面层：文件树、正文渲染、查找与局部状态反馈。

本期进度

  • 核对 mygo v0.9.0 多窗口 API
  • 锁定渲染库与安全配置
  • 真实 Windows 11 窗口验收

渲染管线

Go 侧解析 Markdown 并清理 HTML，前端只负责公式与图表。单次渲染的期望耗时满足 t ≤ 1.5s，P95 统计口径为：

P95 = minx { x : 1n n∑i=1 1(ti ≤ x) ≥ 0.95 }
go 
// Render 在后台 goroutine 中执行，窗口关闭时 ctx 被取消
func (DocService) Render(ctx context.Context, req contract.RenderRequest) (contract.RenderResult, error) {
    if req.Size > 10 << 20 {
        return contract.RenderResult{}, contract.ErrTooLarge("单个文件最大 10 MiB")
    }
    return render.Document(ctx, req)
}
