## 2. 已知边界

- 移动的目标目录对话框是系统原生对话框，未能自动脚本化；同盘移动、重名、脏窗口与跨盘复制回退由 Go 测试覆盖，真实对话框留待用户验收。
- 跨盘移动使用复制、SHA-256 校验、替换、删除源文件；保留修改时间与权限位，但 ACL 按 Windows 复制语义继承目标目录，而不是复制源文件 ACL。
- `Shell.ShowItemInFolder` 不返回错误，Explorer 启动失败无法提示；应用只保证文件存在且为已落盘文档。
- 移动与另一窗口立即开始编辑的极端并发未做专门原生测试；Go 在移动后保留窗口脏标记，保存锁与保存前路径复查防止旧路径被重新创建。
- 文件树 Delete 只在树获得焦点时触发；编辑器焦点下 Delete 仍只删除文本。原生脚本未单独复验树焦点 Delete，页面测试覆盖该分支。
- 混合换行属性显示“混合”；按 P1 规则保存时仍统一为 CRLF。
