# M6-2 验收记录：数学工具

> 对应 `docs/P3-高级工具需求.md` §3.2，验收项 P3-AC-05、P3-AC-06、P3-AC-14。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 行内公式 | 选区包裹 `$...$`，再次执行解包；无选区插入 `$公式$` 并选中占位文字 |
| 块级公式 | 编辑菜单入口复用既有 `Ctrl+Shift+M` 公式块命令 |
| 模板 | 分数、根号、上标、下标、矩阵、分段函数、多行对齐、求和、积分、极限；插入后选中第一个占位内容 |
| 定界符转换 | `$...$`、`\(...\)`、`$$` 块、`\[...\]` 块之间转换；跨公式、代码或行内正文包围时拒绝 |
| 检查公式 | 用现有 KaTeX 配置解析当前公式，状态栏显示“公式有效”或真实错误；不自动修改 |
| 菜单使能 | 编辑模式且光标不在代码/front matter；转换与检查要求光标在公式内；禁用项显示原因 |
| 上下文 | `EditorContext` 新增 `inMath` / `mathBlocked`，数学模块懒加载，不进入阅读首包 |

## 4. 边界与未覆盖

- 定界符转换与非法公式错误显示由自动测试覆盖，原生未逐项点击四种转换。
- 源码内实时公式预览、CAS、求解、OCR 不在本期范围。
- 块级公式转换为行内时会把环境中的源码换行折叠为空格，保持单行；复杂环境仍依赖 KaTeX 渲染结果。
- 光标位于块级公式内时模板项禁用，只允许检查与定界符转换。
