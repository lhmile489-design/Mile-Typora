# M1 技术验证报告

> 阶段：M1（技术验证），门禁 G3（docs/开发计划.md §1.5）。
> 日期：2026-11-16。对应 PRD 13.1 的 M1 完成标准：原生多窗口互不干扰；六种图表及公式正常；恶意内容不能绕过安全限制。
> 本文只写实测结果。没有测到的写在"未覆盖"一节，不当成已通过。

## 1. 结论

| PRD 13.2 的风险 | 结论 | 证据 |
| --- | --- | --- |
| 锁定的 mygo 版本多窗口能力与预期不符 | 满足 | 一个进程 10 个窗口；关一窗其余可用；最后一窗关闭进程退出（M1-1） |
| 多窗口事件错投或旧请求覆盖新文件 | 满足（机制先行） | `Emit(win)` 定向事件；打开请求队列 + `Pending`/`Ack`；第二实例参数只交给有焦点的窗口（M1-2） |
| 大目录、复杂 Markdown、大图耗尽资源 | 机制就绪，未压测 | 扫描与读取有上限；渲染有 8 秒超时；体积、条目上限在 M3-7 测 |
| 公式 / Mermaid 输入复杂或含恶意指令 | 满足 | init 指令被拒绝；strict 模式；DOMPurify 去 `<img>`；本地降级（D-T19） |

M1 的完成标准逐条成立，建议进入 M2。

| 项目 | 结果 |

## 3. 打开请求

- 队列是唯一真相：每窗口 32 条，页面 `Pending` 取、`Ack` 确认，未确认的请求可重复取。React StrictMode 首次挂载丢弃响应也不会丢请求（D-T15）。
- 原生：带 2 个启动参数时状态栏显示"待打开（2）"；已就绪的页面收到第二实例参数显示"待打开：…"。
- 队列满返回 `queue_full`，不挤掉未确认的请求。

## 4. 渲染与安全

| 项目 | 结果 |
| --- | --- |
| 原始 HTML | 转义成文本显示（`pre.raw-html`），不执行、不丢弃 |
| 白名单 | bluemonday，仅本项目产物所需的标签与属性；无 `style`、`on*`、iframe、object、svg |
| 恶意样本 | 脚本、事件属性、`javascript:`、`data:`、内联样式、SVG、iframe 全部拦下，正文文字仍可读 |
| 模糊测试 | 60 秒约 240 万次执行，无 panic、无危险输出（`FuzzRender`） |
| 安全断言方式 | 用 `x/net/html` token 流遍历，不靠子串匹配（转义文本里本来就有 `<script>` 字样） |

## 5. 公式与图表（D-T19）

| 项目 | 结果 |
| --- | --- |
| `%%{init}%%` | mermaid 12.3.0 的 secure 配置改不动：`securityLevel` 仍为 strict，`themeVariables` 不生效。产品仍在渲染前拒绝带 init 的图表 |

| 块级公式解析 | passthrough v0.6.0 的块级形式不产出节点，goldmark 块解析器会吞掉中间行；改为解析前把 `$$`/`\[` 改写成内部围栏（D-T19） |

## 6. 本地图片（D-T20）

- 页面只看到 `http://mtres.localhost/<128 位 token>`；没有 token 取不到文件。
- 文件头识别：PNG / JPEG / GIF / WebP 放行；伪造成 `.png` 的 SVG 返回 415。
- 上限：20 MiB（文件）、2500 万像素（`image.DecodeConfig`，不解码像素）。
- 不能显示的图片（远程、越界、不存在、格式、超限）换成带原因的占位块，保留 alt。
- 测试覆盖：伪扩展名、超大文件、造 100000×100000 的 PNG 头、路径型 token、跨窗口 token。

## 8. 文件监听（FR-07 的可行性）

试验程序（临时命令 `cmd/watchprobe`，已验证后删除）在真实窗口进程内用 `mygo.WatchFiles` 监听一个文件，依次做三种改动，输出：

```text
plain save: write .
plain save: 1 event(s)
atomic save: write .
atomic save: 1 event(s)
delete: remove .
delete: 1 event(s)
```

- 普通保存（覆盖写）与原子替换（临时文件 + 改名）都报一次 write，去抖 80 ms 生效。
- 删除报 remove。
- 结论：`WatchFiles` 满足 FR-07 的事件需求，M3-4 可以直接把它接到刷新上。
