# M5-6 验收记录：导出 HTML / PDF 与打印

> 对应 `docs/P2-效率与排版需求.md` §9，验收项 P2-AC-19、P2-AC-20、P2-AC-21。
> 自动验证与原生验收分开记录；系统保存/打印对话框不能稳定脚本化的部分标为边界。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 导出 HTML（FILE-16） | 页面增强后的正文 → 独立导出清理器 → 固定模板；公式 MathML、Mermaid 内联 SVG、本地图片 data URI、远程图片占位、20 MiB 图片预算、原子写入 |
| 导出 PDF（FILE-16） | 同一份导出文档加载到隔离打印视图，`Page.PrintToPDF`，A4 纵向、0.6 英寸边距、打印背景、30 秒预算 |
| 打印（FILE-17） | 独立打印视图打开 WebView2 打印预览；应用外壳不进入打印产物；`Alt+Shift+P` 与文件菜单共用命令 |
| 菜单 | 文件 → 导出子菜单（HTML… / PDF…）、打印…；导出期间禁用并显示进行中 |
| 未落盘文档 | 编辑缓冲经同一渲染管线导出，默认名“未命名.html / 未命名.pdf” |
| 警告 | 图片超限、远程/缺失图片省略后，界面逐条列出 |

## 2. 自动验证

| 命令 | 结果 |
| --- | --- |
| `go test ./...` | 228 项通过，14 个包 |
| `bunx vitest run` | 311 项通过，20 个文件 |
| `bun run typecheck` | 通过 |
| `bun run build:web` | 生产构建通过（保持既有大于 500 kB 分包警告） |

覆盖点：

- 导出清理：脚本、事件属性、样式/类名、远程图片、`javascript:` 与控制字符 href 被拒绝；MathML、SVG 文本标签、表格、代码、安全链接保留；chroma `fm` token（如 `__init__`）不再被误删。
- 图片：`mtres` 令牌只允许本窗口、相对路径重新授权；PNG/JPEG/GIF/WebP 转 data URI；总量超 20 MiB 省略并警告。
- 文件：取消不写、错误扩展名拒绝、原子写入、PDF 失败/超时不写部分文件；单飞槽阻止重复导出。
- 页面：源码/阅读/编辑缓冲导出正文、标题与默认名；菜单与 `Alt+Shift+P`；警告对话框；公式重复排版保护。

## 3. 原生验收

环境：Windows 11 真实窗口，`testdata/render/m5-6.md`（公式、表格、Mermaid、图片、长段落），开发服务器 5273，调试端口 9222。

| 操作 | 结果 |
| --- | --- |
| 文件 → 导出 → HTML… | 生成单文件 23,061 字节；`<html lang="zh-CN">`、标题、MathML、内联 SVG、`data:image/png;base64` 均存在；无 `<script>`、工具栏/侧栏/状态栏、远程 `<img>`；远程图片显示占位说明 |
| 文件 → 导出 → PDF… | 生成 176,007 字节、3 页；第 1 页公式与表格正确，第 2 页 Mermaid 显示“开始/判断/结束”文字与连线、图片与远程占位，第 3 页长段落继续分页；无应用界面 |
| 文件 → 打印… | 打开 `edge://print/` 打印预览；独立打印视图页面为纯文档，含 5 个 MathML，应用外壳不出现 |
| 打印取消 | 系统打印预览属于系统 UI，未脚本化关闭；打印窗口按设计保留为纯文档窗口，正文与磁盘文件未修改 |

说明：系统保存对话框无法稳定脚本化（D-T17）。本次原生导出使用开发期临时固定目标路径完成写入与产物检查，钩子在提交前已移除；保存对话框本身的交互与默认文件名由自动化测试和代码路径覆盖。

## 4. 边界与未覆盖

- 保存对话框、系统打印预览的按钮交互未做自动化点击；打印取消后的窗口关闭由用户完成。
- 20 MiB 图片预算、PDF 30 秒超时由 Go 测试与代码路径覆盖，未构造原生超大样本。
- PDF 使用可见但独立的打印窗口（隐藏/离屏窗口实测为空白 PDF），窗口在 PDF 完成后自动关闭；打印窗口保留供用户关闭。
- 导出 HTML 在其他浏览器中的 MathML/SVG 渲染未逐一验收，本机结构与离线资源已检查。
