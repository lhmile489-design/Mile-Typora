# 接口契约

> 前端经 `src/lib/transport.ts` 调用的 Go 绑定方法、事件和错误码清单。代码是权威：改了 `internal/service/` 的导出方法、`internal/contract/` 的类型或事件后，运行 `bun run generate`，并同步本文。
> 最后更新：2026-11-17（M5-2 左侧视图与目录搜索）

## 1. 通用约定

- 绑定方法的第一个参数是 `context.Context`，生成的 TypeScript 函数里没有这个参数。Go 用 `mygo.CallerWindow(ctx)` 确定调用窗口，不接受前端传来的窗口 ID 或绝对路径。
- **可预期的失败**放在返回值的 `failure` 字段（`contract.Failure`）。前端的 `CallError` 只有 `message` 和 `method`，带不了错误码（decisions.md D-T01）。
- **意外故障**（程序缺陷、窗口上下文丢失）返回 Go `error`。前端 `transport.ts` 的 `wrap()` 把它转成 `{ ok: false, message }`，界面显示通用错误。
- JSON 字段一律用小驼峰。

### 1.1 Failure

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | string | 错误码，见第 3 节 |
| `detail` | string | 给用户看的一句话，不含正文和未授权路径 |
| `size` | number，可选 | `too_large` 时的实际大小（字节） |
| `limit` | number，可选 | `too_large` 时的上限（字节） |

## 2. 绑定方法

### WindowService.Ready

- **TS**：`WindowService.ready(): Promise<ReadyInfo>`；组件通过 `transport.ready(): Promise<Outcome<ReadyInfo>>` 调用。
- **用途**：页面加载后的就绪握手，确定当前窗口，并把该窗口标记为就绪（之后的打开请求会以事件提示）。请求本身由 `Pending` 取，`Ack` 确认，见下文。
- **返回 `ReadyInfo`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `windowId` | number | `win.ID()`，只用于显示和日志，前端不能用它定位窗口 |
| `version` | string | 应用版本；开发期可能为空，界面显示为 `dev` |
| `startupNotice` | string，可选 | 本次启动为什么没有恢复上次的内容（例如"上次阅读的内容已不存在，已打开空白页"），页面在状态栏提示 |

- **error**：
  - `no calling window`（`service.ErrNoCallerWindow`）：调用没有来源窗口
  - `calling window is not open`（`service.ErrWindowNotOpen`）：来源窗口不在注册表里，属程序缺陷

### WindowService.Pending

- **TS**：`WindowService.pending(after: number): Promise<PendingResult>`；组件通过 `transport.pending(after)` 调用。
- **用途**：取出 seq 大于 `after`、且页面尚未确认的打开请求，按 seq 升序。
- **返回 `PendingResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `requests` | OpenRequest[] | 未确认的请求；没有时为空数组 |

`OpenRequest`：`seq`（number，窗口内递增，用于去重与排序）、`path`（string，可选，命令行参数或页面请求的路径）。

- **幂等**：未确认的请求会在每次调用时重新返回。页面重挂载或重新加载后重新取一次，不会丢请求（PRD §9.2.3）。

### WindowService.Ack

- **TS**：`WindowService.ack(seq: number): Promise<void>`。
- **用途**：确认 seq 及之前的请求都已被页面处理，从队列中释放。旧的 seq 不会回退。
- **error**：来源窗口无效时同 `Ready`。

### WindowService.OpenRequested

- **TS**：`WindowService.openRequested(seq: number): Promise<LoadResult>`；组件通过 `transport.openRequested(seq)` 调用。
- **用途**：打开某个打开请求指向的文件——文件关联、命令行参数、第二个实例。路径来自操作系统，用户启动应用即授权；仍过真实路径、扩展名、10 MiB、UTF-8 与渲染检查。
- **返回 `OpenRequestResult`**：`kind` 为 `file`（带 `doc`；若文件在窗口当前目录内，另带 `rel`，页面据此保留文件树）或 `folder`（带 `folder.root` / `folder.name`）；`kind` 为空表示请求交给了新开的窗口；`failure` 见错误码。
- **确认**：处理完（无论成功失败）即 `Ack(seq)`。同一 `seq` 再次调用时返回窗口当前内容（文档或文件夹），页面重挂载（React StrictMode）或刷新不会丢。
- **错误码**：请求已处理且窗口没有内容时返回 `request_expired`。

### WindowService.GetSettings

- **TS**：`WindowService.getSettings(): Promise<SettingsResult>`。
- **用途**：读设置与最近列表。应用数据目录不可用时返回 `settings_unavailable`（仍按默认值返回）；配置文件损坏时 `corrupt: true` 并带 `settings_corrupt`，`detail` 说明原文件已保留。
- **返回**：`settings.startup`（`blank` / `resume`）、`settings.appearance`（`system` / `light` / `dark`）、`settings.showStatusBar`（默认 `true`，M5-7 VIEW-09）、`settings.recent`（最多 20 条，新的在前，含 `path`、`name`、`isDir`）。

### WindowService.SaveSettings

- **TS**：`WindowService.saveSettings(view)`。
- **用途**：写 `startup`、`appearance` 与 `showStatusBar`；最近列表由 Go 维护，页面传入的值被忽略。写入失败返回 `settings_write_failed`（"本次设置未保存"），旧值保持不变。`showStatusBar` 变化时向所有窗口发 `settings-changed` 事件。

### WindowService.ClearRecent

- **TS**：`WindowService.clearRecent()`：清空最近列表；失败返回 `settings_write_failed`。

### WindowService.OpenRecent

- **TS**：`WindowService.openRecent(path)`：只接受最近列表里已记录的路径（大小写不敏感比较），否则 `not_found`；文件按单文件打开、文件夹按目录打开，返回 `OpenRequestResult`。

### WindowService.RemoveRecent

- **TS**：`WindowService.removeRecent(path): Promise<void>`；组件通过 `transport.removeRecent(path)` 调用。
- **用途**：移除一条已失效的最近记录（PRD §7.2、FR-08.3）。只影响应用元数据，不删除源文件；路径不在列表里时什么也不做。页面只在 `not_found` / `permission` / `out_of_scope` 时自动移除，超限与编码错误保留记录。

### WindowService.Refresh

- **TS**：`WindowService.refresh(): Promise<LoadResult>`；组件通过 `transport.refresh(): Promise<OpenFileResult>` 调用。
- **用途**：重新读取当前窗口的文档（`F5`、工具栏"刷新"、过期提示条的"重试"、PRD FR-07.8）。Go 重新走一遍规范化、读取、渲染，返回新的 `LoadResult`；失败时页面保留旧内容并显示原因（PRD FR-07.11）。
- **无文档**：窗口没有打开文档时返回 `not_found`（"尚未打开文档"），不抛错。
- **与自动刷新共用**：自动刷新监听每个文件只有一份（`internal/watch.Pool`），多个窗口显示同一文件时共享，最后一个窗口关闭才停止；自动刷新结果经 `doc-updated` 事件推送，seq 递增。手动刷新只回答调用窗口。文件所在的目录消失或改名时监听以 `Gone` 结束，Go 会再读一次并把失败推给页面，旧内容按过期处理。

### WindowService.RenderSource

- **TS**：`WindowService.renderSource(text: string): Promise<RenderSourceResult>`；组件通过 `transport.renderSource(text): Promise<SourcePreview>` 调用。
- **用途**：把编辑缓冲渲染成预览 HTML，使用与文件渲染完全相同的 goldmark 管线与白名单，不读盘、不写盘（PRD 10.1、M4-1）。
- **返回**：`html`、`counts`（公式 / 图表数量）；失败放 `failure`，页面保留编辑模式并提示原因。
- **限制**：不接受超过 10 MiB 的文本，不接受非法 UTF-8；返回 `too_large` / `encoding`。
- **图片**：预览使用独立的 token 类型（`preview`），每次预览前只清理上一次预览的 token，阅读视图的 token 不受影响；没有打开文件时图片显示“尚未保存的文档不能显示本地图片”。

### WindowService.CloseDocument

- **TS**：`WindowService.closeDocument(): Promise<void>`；组件通过 `transport.closeDocument()` 调用。
- **用途**：关闭当前文档，窗口回到空白页；文件树保留（PRD FR-07.5 的"关闭当前文档"入口）。Go 停止该窗口的监听引用，清空窗口的当前文件，并把启动恢复目标改为剩余内容（有目录时恢复目录，否则清除）。
- **失败**：来源窗口无效时同 `Ready`。

### WindowService.CloseWindow

- **TS**：`WindowService.closeWindow(force: boolean): Promise<void>`；组件通过 `transport.closeWindow(force)` 调用。
- **用途**：关闭当前窗口（`Ctrl+W`，PRD FR-09）。`force=false` 时若缓冲有未保存修改返回 `ErrWindowDirty`；页面完成保存 / 放弃后传 `true`。关闭的是最后一个窗口时应用退出。
- **原生关闭**：标题栏关闭先由 Go 检查 `SetEditState` 的脏标记；脏时阻止关闭并发出 `close-requested` 事件，页面弹三选一。
- **失败**：来源窗口无效时同 `Ready`；脏缓冲未处理时为 `ErrWindowDirty`。

### WindowService.SetEditState

- **TS**：`WindowService.setEditState(dirty, hash, hasBOM, lineEnding)`；组件在缓冲变脏、保存成功或换文档时调用。
- **用途**：让 Go 知道窗口是否有未保存修改，以及保存要保留的 BOM / 换行与冲突基线。哈希来自当前 `Doc.hash`。
- **换行值**：`lineEnding` 为 `LF`、`CRLF` 或 `混合`。混合文件未转换直接保存时 Go 统一写 CRLF；页面选择转换为 LF/CRLF 后传所选值（M5-8 EDIT-19），保存结果的 `lineEnding` 回填窗口状态。

### WindowService.SaveDocument

- **TS**：`WindowService.saveDocument(text, force): Promise<SaveResult>`；组件通过 `transport.saveDocument(text, force)` 调用。
- **用途**：把编辑缓冲写回窗口当前文件（PRD 10.2）。校验 UTF-8 与 10 MiB；按 `SetEditState` 的 BOM / 换行写回；先比较磁盘哈希与基线，变化时返回 `conflict`，文件消失返回 `missing`；`force=true` 只在用户确认覆盖或重新创建后使用。
- **写入**：同目录临时文件 + `ReplaceFileW`，保留原 ACL/属性；失败保留原文件并返回 `save_failed`。
- **返回**：`path`、`name`、`size`、`hash`、`hasBom`、`lineEnding`；失败在 `failure`（`no_path`、`conflict`、`missing`、`save_failed`、`too_large`、`encoding`）。
- **副作用**：成功后更新基线、清除脏状态，并忽略这次保存产生的文件监听事件。

### WindowService.SaveDocumentAs

- **TS**：`WindowService.saveDocumentAs(text): Promise<SaveResult>`。
- **用途**：系统另存为对话框选路径；未写扩展名时补 `.md`，只接受 Markdown 扩展名；成功后窗口切换到新路径、重新监听、记入最近记录与恢复目标；原文件不变。取消返回 `cancelled`。

### WindowService.SaveAll / ReportSaveAll

- **TS**：`WindowService.saveAll(): Promise<SaveAllStart>`、`WindowService.reportSaveAll(requestId, name, status, message): Promise<void>`；组件通过 `transport.saveAll()` / `transport.reportSaveAll(...)` 调用。
- **用途**：保存全部（P1 FILE-10）。`SaveAll` 记录发起窗口，按打开窗口快照逐个发出 `save-all-request`；每个窗口保存完自己的脏缓冲后调用 `ReportSaveAll` 报告 `clean` / `saved` / `failed` / `unhandled`，Go 汇总后向发起窗口发 `save-all-done`。一次只处理一个窗口，未命名缓冲与冲突对话框不会同时抢焦点。
- **保存语义**：实际写盘仍由各窗口复用 `SaveDocument` / `SaveDocumentAs` 与冲突对话框完成；无路径走另存为，取消或失败保持脏状态。同一文件多窗口的冲突交给保存时的哈希基线流程处理，不静默覆盖。
- **窗口关闭**：运行中关闭窗口会把它记为 `unhandled` 并继续；每个窗口有 5 分钟响应期限，超时记为未处理。
- **失败**：已有一次保存在进行时再次调用返回调用错误“保存全部正在进行”；过期或非当前窗口的报告返回“保存全部请求已失效”。

### WindowService.ClipboardReadText / ClipboardWriteText

- **TS**：`WindowService.clipboardReadText(): Promise<string>`、`WindowService.clipboardWriteText(text: string): Promise<void>`；组件通过 `transport.readClipboardText()` / `transport.writeClipboardText(text)` 调用。
- **用途**：源码编辑器的"复制为 Markdown"与"粘贴为纯文本"（P1 EDIT-08 / EDIT-11）。走 mygo 原生剪贴板，不调用 WebView 的 `navigator.clipboard`，避免读取剪贴板时弹出 `edge://permission-request-dialog/` 权限页。
- **返回**：读取返回纯文本，剪贴板为空时返回空字符串；写入没有返回值。系统剪贴板不可用时调用抛出 `CallError`，`transport` 转成 `{ ok: false, message }`，页面提示"无法读取剪贴板，请使用 Ctrl+V"。
- **边界**：只处理纯文本，不执行 HTML、不解析富文本；每次粘贴在编辑器里是一次可撤销编辑。M5-5 起编辑模式的 `Ctrl+V` 由页面接管：优先粘贴纯文本，文本为空时尝试剪贴板图片；`Ctrl+Shift+V` 仍是纯文本。`Ctrl+C` / `Ctrl+X` 仍由 WebView 处理。

### WindowService.ClipboardCopyPlainText

- **TS**：`WindowService.clipboardCopyPlainText(source: string): Promise<ClipboardResult>`；组件经 `transport.copyPlainTextSource(source)` 调用。
- **用途**：把源码选区渲染成可读文本写入剪贴板（M5-5 EDIT-07）。标题、列表、引用、强调、链接标记都被去掉；表格单元格用制表符、行用换行；代码块保留代码文本；图片保留替代文字。
- **返回 `ClipboardResult`**：成功时没有字段；失败时 `failure`。
- **失败码**：`empty_selection`、`render_failed`、`clipboard_failed`。
- **边界**：只写剪贴板，不修改文档；不访问网络。

### WindowService.ClipboardCopyHTML

- **TS**：`WindowService.clipboardCopyHTML(content: string, fromSource: boolean, simplified: boolean): Promise<ClipboardResult>`；组件经 `transport.copyClipboardHTML(content, fromSource, simplified)` 调用。
- **用途**：把一个选区以清理后的 HTML 与纯文本回退同时写入同一个剪贴板 Item（M5-5 EDIT-09/EDIT-10）。`fromSource=true` 时 `content` 是 Markdown 源码，由 Go 渲染；否则 `content` 是阅读/预览区选中的 HTML 片段。
- **清理**：HTML 与简化格式使用两套白名单；脚本、事件属性、样式、类名、id、远程资源与本地图片都不会进入片段。普通 HTML 保留标题、段落、列表、引用、代码、表格与安全链接；`simplified=true` 只保留 `p`、`br`、`strong`、`em`、`ul`、`ol`、`li`、`blockquote`、`code`、`a[href]`，标题降为加粗段落，表格与图片整体移除。
- **剪贴板写法**：`transfer.NewItem(transfer.Bytes(transfer.HTML, …), transfer.Bytes(transfer.Text, …))`，再 `Clipboard.Write(transfer.New(item))`；不会退化为只写 HTML 或只写文本。
- **失败码**：`empty_selection`、`render_failed`、`clipboard_failed`。

### WindowService.ClipboardCopyImage

- **TS**：`WindowService.clipboardCopyImage(source: string): Promise<ClipboardResult>`；组件经 `transport.copyImageToClipboard(source)` 调用。
- **用途**：复制一张已授权的本地图片（M5-5 EDIT-05）。`source` 可以是编辑器图片语法里的相对引用，也可以是阅读/预览区图片的 `http://mtres.localhost/<token>` 地址。
- **授权**：相对引用经 `pathguard.Canon`、`Within`、`CheckComponents` 与 `resource.Check`，只允许文档目录内；`mtres` 地址必须由调用窗口注册，其他窗口的令牌返回 `not_found`。远程地址、绝对路径与越界路径拒绝。
- **转换**：PNG/JPEG/GIF/WebP 解码后统一用 `image/png` 重编码，再以 `transfer.PNG` 写入剪贴板；单图上限 20 MiB / 2500 万像素。
- **失败码**：`not_found`、`out_of_scope`、`too_large`、`unsupported_type`、`image_failed`、`clipboard_failed`。
- **边界**：不修改文档，不联网；被阻止的远程或未授权图片不能借此加载。

### WindowService.ClipboardReadImage

- **TS**：`WindowService.clipboardReadImage(): Promise<ImagePickResult>`；组件经 `transport.readClipboardImage()` 调用。
- **用途**：把系统剪贴板中的图片转成待确认的 `assets/` 写入（M5-5 EDIT-06）。返回结构与 `PickImage` 相同：`token`、`name`、`target`、`size`、`failure`；剪贴板没有图片时 `failure.code = no_image`。
- **行为**：先读取剪贴板；PNG 原样使用，其他可解码格式转为 PNG；检查 20 MiB / 2500 万像素与转码后的 PNG 大小。未落盘文档返回 `no_file`。确认前不写文件，确认仍走 `CopyImage`。
- **失败码**：`no_image`、`no_file`、`out_of_scope`、`too_large`、`unsupported_type`、`image_failed`。
- **授权**：与 `PickImage` 相同的文档与工作区检查；确认时 `CopyImage` 会再次检查工作区与目标是否已被占用。

### WindowService.ExportHTML / ExportPDF

- **TS**：`WindowService.exportHTML(bodyHTML: string, title: string): Promise<ExportResult>`、`WindowService.exportPDF(bodyHTML: string, title: string): Promise<ExportResult>`；组件经 `transport.exportHTML` / `transport.exportPDF` 调用。
- **用途**：把页面已经增强的正文（MathML、Mermaid SVG、mtres 图片引用）导出为独立 HTML 或 PDF（M5-6 FILE-16）。
- **输入**：`bodyHTML` 是当前阅读/预览文章或编辑缓冲经同一渲染管线增强后的正文；`title` 用于 `<title>` 与默认文件名，扩展名由 Go 去掉并按格式追加。
- **HTML 处理**：Go 用独立导出白名单清理；本地图片经 `mtres` 令牌或文档相对路径重新授权、读取并转成 `data:image/(png|jpeg|gif|webp);base64,`；内嵌图片总量上限 20 MiB，超限图片以占位说明替代并出现在 `warnings`；远程图片不请求。导出模板是固定字符串，不接受文档提供的样式/类名。
- **PDF 处理**：同一份导出文档加载到独立打印视图，使用 `Page.PrintToPDF`，A4 纵向、四边 0.6 英寸、打印背景；30 秒超时，失败或超时不创建目标文件。输出不含工具栏、侧栏、状态栏或编辑器界面。
- **返回 `ExportResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `path` | string | 用户选择的输出文件绝对路径 |
| `warnings` | string[] | 省略的图片等警告，界面逐条列出 |
| `failure` | Failure，可选 | 取消或失败原因 |

- **失败码**：`cancelled`、`busy`、`export_failed`、`pdf_failed`、`timeout`、`unsupported_type`、`permission`。
- **写入**：保存对话框选择目标，`docwrite` 原子替换；取消不写文件。导出与打印共用单飞槽，进行中再次调用返回 `busy`。

### WindowService.PrintDocument

- **TS**：`WindowService.printDocument(bodyHTML: string, title: string): Promise<PrintResult>`；组件经 `transport.printDocument` 调用（`Alt+Shift+P`）。
- **用途**：在独立打印视图上打开 WebView2 打印预览（M5-6 FILE-17）；不打印编辑器页面。
- **行为**：与 PDF 共用导出文档与清理；打印视图不注册进窗口注册表，不接收打开请求。打印窗口在预览打开后保留为纯文档窗口，由用户关闭；正文与文档文件不受影响。
- **返回 `PrintResult`**：`warnings`、`failure`。
- **失败码**：`busy`、`print_failed`、`export_failed`。

### WindowService.GetWindowView / SetFullScreen / SetAlwaysOnTop / SetZoom

- **TS**：`WindowService.getWindowView(): Promise<WindowViewState>`、`setFullScreen(value: boolean)`、`setAlwaysOnTop(value: boolean)`、`setZoom(factor: number)`；组件经 `transport` 的同名方法调用（M5-7 VIEW-11..15）。
- **用途**：只改变调用窗口的全屏、置顶与整页 WebView2 缩放；前端不传窗口 ID，Go 用 `mygo.CallerWindow(ctx)` 定位。
- **返回 `WindowViewState`**：`fullScreen`、`alwaysOnTop`、`zoom`（0.5–2.0）、`failure`。
- **缩放**：步进 10%，范围 50%–200%；超出范围由 Go 夹到边界。缩放含工具栏与状态栏，不修改系统 DPI，不影响其他窗口。
- **状态**：全屏、置顶、缩放均为每窗口会话状态，不写入设置；全屏退出由 mygo 恢复原窗口尺寸与位置。
- **失败码**：`view_unavailable`、`zoom_invalid`。

### WindowService.CycleWindow

- **TS**：`WindowService.cycleWindow(backwards: boolean): Promise<WindowCycleResult>`；`Ctrl+Tab` / `Ctrl+Shift+Tab` 调用。
- **用途**：按最近使用顺序聚焦下一个/上一个本应用窗口（M5-7 VIEW-16）。只在本应用窗口间循环，不新建窗口、不引入标签页，也不切换到打印视图。
- **行为**：Go 侧窗口注册表维护创建顺序，`RecordFocus` 维护 MRU；没有焦点历史时按创建顺序。只有一个窗口时无操作。对话框打开时页面不派发该命令。
- **失败码**：`cycle_failed`。

### WindowService.CountWords

- **TS**：`WindowService.countWords(source: string): Promise<WindowCount>`；组件经 `transport.countWords(source)` 调用。
- **用途**：统计源码选区或全文（M5-7 VIEW-10），不修改文档、不写盘。
- **口径**：CJK 字符每字 1 个词；连续拉丁字母、数字、下划线 1 个词；字符数含/不含空白；段落数为解析后的段落、标题与代码块；排除 YAML front matter 与注释；代码块与公式源码计入字符，代码标识符按 1 个词。
- **返回 `WindowCount`**：`characters`、`charactersNoSpaces`、`words`、`paragraphs`、`failure`。
- **失败码**：`no_file` 以外的调用错误；正常统计不返回失败。

### WindowService.NewDocument

- **TS**：`WindowService.newDocument(): Promise<NewWindowResult>`；组件通过 `transport.newDocument()` 调用（`Ctrl+N`）。
- **用途**：开始一个未保存 Markdown 缓冲：当前窗口为空时复用，否则新建窗口；不立即写盘。目标窗口的 `ReadyInfo.startUntitled` 为 true，页面据此进入编辑模式；页面调用 `clearStartUntitled()` 关闭该标记。

### WindowService.OpenLink

- **TS**：`WindowService.openLink(href: string): Promise<LinkTarget>`；组件通过 `transport.openLink(href)` 调用。
- **用途**：文档里点到链接时由 Go 判断该做什么（PRD FR-06）。页面永远不自己导航：所有点击都 `preventDefault`。
- **返回 `LinkTarget.kind`**：
  - `anchor`：带 `anchor`（去掉 `#` 的片段），页面滚动到该元素；
  - `document`：带 `rel`（相对窗口根目录），页面按文件树的方式打开；
  - `attachment` / `blocked`：带 `reason`，页面显示在状态栏；
  - `handled` / `cancelled`：Go 已经做完（打开浏览器、开了新窗口）或用户取消，页面不用处理。
- **确认**：外链与工作区外文件由 Go 弹原生对话框，按钮为"取消 / 打开"，默认按钮是"取消"（回车不会误开）。
- **拒绝**：`javascript:`、`data:`、`file:`、自定义协议、绝对路径、`../` 越界的链接一律 `blocked`，不会读取文件、不会联网。

### WindowService.OpenTreeFile

- **TS**：`WindowService.openTreeFile(rel: string, newWindow: boolean): Promise<OpenRequestResult>`。
- **用途**：文件树里点开的文件。`rel` 是相对窗口根目录的路径，Go 用 `pathguard.Within` 判范围，越界返回 `out_of_scope`。
- **行为**：`newWindow` 为 false 时在当前窗口打开并返回 `kind: "file"`；为 true 时新开窗口、把文件作为请求交给它，返回空 `kind`，当前窗口的目录上下文不变（PRD FR-02.4、AC-06）。

### WindowService.OpenFolderDialog

- **TS**：`WindowService.openFolderDialog(): Promise<OpenFolderResult>`；组件通过 `transport.openFolder()` 调用。
- **用途**：弹出系统文件夹对话框，用户选中的文件夹即窗口的工作区根（PRD FR-03）。成功后窗口记录根目录，供 `Scan` 使用。
- **返回 `OpenFolderResult`**：`root`（规范化后的绝对路径）、`name`（文件夹名）；`root` 为空表示取消；`failure` 为可预期问题（`not_found`、`permission`、`unsupported_type`、`out_of_scope`）。

### WindowService.Scan

- **TS**：`WindowService.scan(frames: Channel<ScanFrame>): Promise<void>`；组件通过 `transport.scan(onFrame)` 调用。
- **用途**：把窗口当前根目录的文件树分批推给页面（每帧最多 500 条），最后一帧 `done: true` 并带结果。页面关闭 Channel 即停止扫描。
- **`ScanFrame`**：`entries`（TreeEntry[]）、`done`（boolean）、`truncated`、`bound`（`entries` / `markdown` / `depth`）、`skipped`（按设计跳过的链接、联接与过深目录）、`unreadable`（读不了的目录数，树仍可用）、`failure`（没有打开文件夹时为 `no_folder`）。
- **`TreeEntry`**：`path`（相对根目录、斜杠分隔）、`name`、`isDir`。
- **规则**：只含 Markdown 与通向它们的目录；不跟随链接与目录联接；自然排序；5 万条目 / 1 万份 Markdown / 深度 64 为上限。

### WindowService.OpenFileDialog

- **TS**：`WindowService.openFileDialog(): Promise<LoadResult>`；组件通过 `transport.openFile()` 调用。
- **用途**：弹出系统文件对话框，用户选中的文件即授权（PRD FR-06.1）；随后在 Go 侧规范化路径、校验扩展名、按 10 MiB 上限读取并校验 UTF-8，再渲染为白名单 HTML（单次渲染 8 秒超时）。
- **返回 `LoadResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `doc` | Doc，可选 | 读取成功时的文档 |
| `failure` | Failure，可选 | 可预期的问题；两者都为空表示用户取消 |

`Doc`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 文件名（含扩展名） |
| `path` | string | 规范化后的完整路径，只用于状态栏悬停和后续刷新 |
| `size` | number | 文件字节数 |
| `hasBom` | boolean | 原文件是否带 UTF-8 BOM |
| `lineEnding` | string | `LF` 或 `CRLF` |
| `hash` | string | 文件磁盘字节（含 BOM）的 SHA-256，保存冲突的基线 |
| `text` | string | Markdown 源文，已去除 BOM、CRLF 统一为 LF |
| `html` | string | Go 侧渲染并经白名单清理的 HTML，页面直接注入显示。原始 HTML 以文本形式出现在 `pre.raw-html` / `code.raw-html` 中；代码块是 `div.code[data-lang]`，内含 chroma 的 `pre.chroma` 与短类名 token；标题带 `id`（保留中文，重复加 `-1`）；front matter 是默认折叠的 `details.fm` |
| `counts` | Counts | 本篇的公式与图表数量，含因超限未增强的数量（M3 起状态栏使用） |

文档里的本地图片在 `html` 中以 `http://mtres.localhost/<token>` 出现：token 由 Go 在渲染时登记，只对当前窗口、当前文档有效；页面向该地址请求时由 `mtres` 协议处理器按文件头校验格式（PNG / JPEG / GIF / WebP）、大小（≤ 20 MiB）与像素（≤ 2500 万）后返回。不能显示的图片（远程、越界、不存在、格式不支持、超限）会替换成 `div.limited[data-kind=image][data-reason]`，里面是 alt 文本。

`Counts`：`math`、`mathLimited`、`mermaid`、`mermaidLimited`（均为 number）。文档里的公式是 `span.math[data-display=false]` 与 `div.math[data-display=true]`，图表是 `pre.mermaid-src`，超限块是 `div.limited[data-kind][data-reason]`。

- **error**：来源窗口无效时同 `Ready`；对话框本身出错属意外故障，返回 Go error。
- **副作用**：成功后窗口记录当前文件（`winctx.Window.SetOpenFile`），供后续刷新与启动恢复使用。

### WindowService.NewWindow

- **TS**：`WindowService.newWindow(): Promise<NewWindowResult>`；组件通过 `transport.newWindow(): Promise<Outcome<void>>` 调用。
- **用途**：再开一个窗口（PRD FR-02）。M2-2 引入"空白窗口复用"矩阵后，矩阵只影响打开文件与目录；工具栏"新建窗口"与 `Ctrl+Shift+N` 始终新开。
- **返回 `NewWindowResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `windowId` | number | 新窗口的 ID；有 `failure` 时为 0 |
| `failure` | Failure，可选 | 创建失败时的 `window_failed` |

- **error**：来源窗口无效时同 `Ready`。创建失败属可预期失败，放在 `failure` 里，不抛错。
- **副作用**：新窗口在创建时注册进 `internal/winctx`，它的 `Context()` 在关窗时取消。旧窗口不受影响。

### WindowService.MoveDocument

- **TS**：`WindowService.moveDocument(rel: string): Promise<FileOpResult>`；组件经 `transport.moveDocument(rel)` 调用。
- **用途**：把当前文档或文件树中选中的文件移动到用户选择的目录（M5-1 FILE-09）。
- **参数**：`rel` 为空时移动本窗口当前文档；非空时相对窗口根目录，Go 侧拼回根目录后经 `pathguard.Canon`、`Within`、`CheckComponents` 校验。
- **返回 `FileOpResult`**：`path`（移动后的绝对路径）、`name`（文件名）、`failure`。
- **失败码**：`no_file`、`out_of_scope`、`not_found`、`unsupported_type`、`move_exists`、`dirty_other`、`move_failed`。
- **副作用**：成功后会更新所有打开该文件的窗口的路径、监听、最近记录与恢复目标，并向这些窗口发 `doc-updated`；调用窗口的绑定返回不保证早于事件。

### WindowService.TrashDocument

- **TS**：`WindowService.trashDocument(rel: string): Promise<FileOpResult>`。
- **用途**：把当前文档或文件树中选中的文件移入回收站（M5-1 FILE-14）。永不永久删除。
- **参数**：同 `MoveDocument`。
- **失败码**：`no_file`、`out_of_scope`、`not_found`、`unsupported_type`、`dirty_other`、`trash_failed`。
- **副作用**：成功移除最近记录，停止该文件监听，并向所有打开该文件的窗口发 `file-trashed`。窗口保留内存内容与路径，`SaveDocument` 仍可进入“重新创建”流程。

### WindowService.DocumentProperties

- **TS**：`WindowService.documentProperties(rel: string): Promise<FileProperties>`。
- **用途**：读取当前文档或文件树选中文件的只读属性（M5-1 FILE-11）。
- **失败码**：`no_file`、`out_of_scope`、`not_found`、`permission`、`unsupported_type`。
- **说明**：内容超过读取上限或不是有效 UTF-8 时，仍返回大小、修改时间与只读属性，编码/换行显示“未知”。
- **返回 `FileProperties`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 文件名 |
| `path` | string | 规范化后的绝对路径 |
| `size` | number | 字节数 |
| `encoding` | string | `UTF-8`、`UTF-8 BOM` 或 `未知` |
| `lineEnding` | string | `LF`、`CRLF`、`混合` 或 `未知` |
| `modified` | string | RFC 3339 修改时间 |
| `readOnly` | boolean | Windows 只读属性 |
| `failure` | Failure，可选 | 读取失败；未命名文档由页面本地显示，不调用此方法 |

### WindowService.RevealDocument

- **TS**：`WindowService.revealDocument(): Promise<FileOpResult>`。
- **用途**：在 Windows 资源管理器中定位当前文档（M5-1 FILE-12）。
- **失败码**：`no_file`、`not_found`、`permission`。
- **说明**：mygo 的 `Shell.ShowItemInFolder` 不返回启动错误；定位前只校验文件存在，Explorer 启动本身按尽力而为处理。

### WindowService.AttachParentFolder

- **TS**：`WindowService.attachParentFolder(): Promise<AttachFolderResult>`。
- **用途**：单文件窗口“在侧边栏中显示”时，把当前文档的父目录设为窗口根，保留当前文档与缓冲（M5-1 FILE-13）。
- **返回 `AttachFolderResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `folder` | `{ root, name }` | 新根目录 |
| `rel` | string | 当前文档相对新根的路径 |
| `failure` | Failure，可选 | 失败原因 |

- **失败码**：`no_file`、`not_found`、`out_of_scope`、`permission`。
- **副作用**：更新窗口根、目录监听与恢复目标；不关闭、不重载当前文档。

### WindowService.PickImage

- **TS**：`WindowService.pickImage(): Promise<ImagePickResult>`；组件经 `transport.pickImage()` 调用。
- **用途**：选择本地 PNG/JPEG/GIF/WebP，校验格式与上限，计算写入文档同目录 `assets/` 的目标路径（M5-4 FORMAT-09）。打开系统文件对话框前要求当前文档已落盘。
- **返回 `ImagePickResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 一次性确认令牌；取消选择时为空 |
| `name` | string | 源文件名 |
| `target` | string | 预计写入的绝对路径（`assets/名称.ext`，重名时加 `-1`、`-2`） |
| `size` | number | 源文件字节数 |
| `failure` | Failure，可选 | 选择或校验失败 |

- **失败码**：`no_file`、`out_of_scope`、`not_found`、`permission`、`too_large`、`unsupported_type`、`image_failed`。
- **副作用**：不写任何文件。选择结果记在窗口上下文，新的选择替换旧的未确认项。
- **授权规则**：窗口有工作区根时，文档必须位于根内且路径逐级无重解析点；单文件模式不检查根，确认对话框本身即本次 `assets/` 写入授权。

### WindowService.CopyImage

- **TS**：`WindowService.copyImage(token: string): Promise<ImageCopyResult>`。
- **用途**：用户确认目标路径后，把已选择的图片复制进 `assets/`，返回可插入的相对 Markdown 路径（M5-4 FORMAT-09）。
- **返回 `ImageCopyResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `path` | string | 写入后的绝对路径 |
| `markdown` | string | `assets/` + URL 编码后的文件名 |
| `name` | string | 写入后的文件名（可能带序号） |
| `failure` | Failure，可选 | 复制失败 |

- **失败码**：`not_found`、`out_of_scope`、`permission`、`too_large`、`unsupported_type`、`image_failed`。
- **副作用**：需要时创建 `assets/`；目标已存在、工作区在确认期间改变、路径出现链接/联接或源图失效时拒绝写入。复制使用独占创建，永不覆盖已有文件。令牌一次性，取消后或复制后再次调用即失败。

### WindowService.CancelImage

- **TS**：`WindowService.cancelImage(token: string): Promise<void>`。
- **用途**：用户取消确认时释放选择结果，不写文件（M5-4 FORMAT-09）。
- **副作用**：只清除窗口内匹配的令牌；不删除任何文件。

### WindowService.ExtractOutline

- **TS**：`WindowService.extractOutline(text: string): Promise<OutlineResult>`。
- **用途**：从当前缓冲或文档源码提取标题大纲（M5-2 VIEW-02）；与渲染器使用同一 GFM/公式解析，不渲染、不写盘。
- **返回 `OutlineResult`**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `headings` | OutlineHeading[] | `{ level, text, line }`，`line` 从 1 开始，含 front matter 行 |
| `truncated` | boolean，可选 | 超过 500 个标题时为 true |
| `failure` | Failure，可选 | 非法 UTF-8 或超过 10 MiB |

### WindowService.SearchDirectory

- **TS**：`WindowService.searchDirectory(query: string, frames: Channel<SearchFrame>): Promise<void>`；组件经 `transport.searchDirectory(query, onFrame)` 取得 `{ abort, done }`。
- **用途**：搜索当前已授权目录的 Markdown 文件名与正文（M5-2 VIEW-05）。只搜索 `scan` 已接受的 Markdown 文件，不跟随链接/联接。
- **帧**：每找到一个文件发一帧 `{ matches }`；最后一帧 `{ done: true, truncated, files }`。失败帧带 `failure`。
- **上限**：500 条命中、200 个命中文件；单文件沿用 10 MiB 读取上限，非法 UTF-8 跳过。
- **取消**：页面关闭 Channel，Go 在下一个文件/发送点停止。
- **失败码**：`no_folder`（窗口没有工作区）、`search_failed`（扫描失败）。

## 3. 错误码

| 码 | 出现处 | 含义 |
| --- | --- | --- |
| `window_failed` | `WindowService.NewWindow` | 新窗口创建失败，界面在发起窗口提示，不影响已有窗口 |
| `not_found` | `OpenFileDialog`、`Refresh` | 文件不存在、已被移动，或路径无法解析；`Refresh` 在窗口没有文档时也返回它 |
| `permission` | `OpenFileDialog` | 没有权限读取 |
| `too_large` | `OpenFileDialog`、`Refresh`、`PickImage`、`CopyImage`、`ClipboardCopyImage`、`ClipboardReadImage` | 文档超过 10 MiB，或图片超过 20 MiB / 2500 万像素（含转码后的 PNG） |
| `encoding` | `OpenFileDialog` | 非法 UTF-8，提示转换为 UTF-8 |
| `unsupported_type` | `OpenFileDialog`、`PickImage`、`CopyImage`、`ClipboardCopyImage`、`ClipboardReadImage` | 文档不是 `.md` / `.markdown`（大小写均接受）、选中的是目录，或图片不是 PNG/JPEG/GIF/WebP |
| `out_of_scope` | `OpenFileDialog`、`PickImage`、`CopyImage`、`ClipboardCopyImage` | UNC、设备路径、经过链接/联接的路径，或文档不在工作区内 |
| `request_expired` | `OpenRequested` | 请求已处理过且窗口没有可返回的内容 |
| `no_folder` | `Scan`、`SearchDirectory` | 窗口还没有打开文件夹 |
| `search_failed` | `SearchDirectory` | 目录扫描失败，搜索未完成 |
| `scan_failed` | `Scan` | 文件夹无法读取 |
| `render_timeout` | `OpenFileDialog` | 渲染超过 8 秒，界面保留可操作并允许重试 |
| `render_failed` | `OpenFileDialog`、`ClipboardCopyPlainText`、`ClipboardCopyHTML` | 解析器报错或内部 panic，已捕获，不崩溃 |
| `no_file` | `MoveDocument`、`TrashDocument`、`DocumentProperties`、`RevealDocument`、`AttachParentFolder`、`PickImage`、`ClipboardReadImage` | 当前没有已落盘文档 |
| `move_exists` | `MoveDocument` | 目标目录已有同名文件；不覆盖 |
| `dirty_other` | `MoveDocument`、`TrashDocument` | 同一文件在其他窗口有未保存修改 |
| `move_failed` | `MoveDocument` | 移动或跨盘复制校验失败，源文件保留 |
| `trash_failed` | `TrashDocument` | 回收站不可用；文件未删除 |
| `image_failed` | `PickImage`、`CopyImage`、`ClipboardCopyImage` | 图片选择或复制失败；未写入目标文件 |
| `no_image` | `ClipboardReadImage` | 剪贴板中没有可粘贴的图片 |
| `empty_selection` | `ClipboardCopyPlainText`、`ClipboardCopyHTML` | 选区为空或清理后没有可复制内容 |
| `clipboard_failed` | 所有剪贴板写入方法 | 系统剪贴板写入失败 |
| `cancelled` | `ExportHTML`、`ExportPDF` | 用户取消保存对话框，未写文件 |
| `busy` | `ExportHTML`、`ExportPDF`、`PrintDocument` | 已有导出或打印在进行 |
| `export_failed` | `ExportHTML`、`ExportPDF` | 清理、选择位置或写入失败 |
| `pdf_failed` | `ExportPDF` | 打印视图无法生成 PDF |
| `print_failed` | `PrintDocument` | 打印视图不可用或无法打开预览 |
| `timeout` | `ExportPDF` | PDF 生成超过 30 秒，不写文件 |
| `view_unavailable` | `GetWindowView`、`SetFullScreen`、`SetAlwaysOnTop`、`SetZoom` | 调用窗口不存在或视图控制不可用 |
| `zoom_invalid` | `SetZoom` | 缩放比例不是有限数值 |
| `cycle_failed` | `CycleWindow` | 目标窗口无法聚焦 |

M1-3 起继续登记。已在 skill 中约定的码（`mygo-web-app/references/bindings-and-channels.md` §2）：`not_found`、`permission`、`too_large`、`encoding`、`out_of_scope`、`unsupported_type`、`render_timeout`、`queue_full`。每个码到文案的映射集中在 `src/lib/errors.ts`。

## 4. 事件

| 名称 | 载荷 | 何时发出 | 接收方 |
| --- | --- | --- | --- |
| `theme-change` | `{ appearance: "system" \| "light" \| "dark" }` | 任意窗口在设置里改了外观并保存成功 | 所有窗口（逐个 `Emit`，不用 `Broadcast`） |
| `settings-changed` | `{ showStatusBar: boolean }` | 任意窗口改了显示状态栏并保存成功 | 所有应用窗口；不发给打印视图 |
| `open-request` | `OpenRequest` | 窗口已就绪后又来了打开请求 | 只发给目标窗口（`Event.Emit(win, …)`），不用 `Broadcast` |
| `doc-updated` | `DocUpdate` | 窗口正在看的文件在应用外被写入、原子替换或删除 | 只发给该窗口 |
| `tree-changed` | 空对象 | 窗口的文件夹结构变化：新增、删除、改名，或根目录消失 | 只发给该窗口；页面防抖 250ms 后重扫 |
| `app-notice` | `{ text: string }` | 应用拒绝或无法完成一次打开（例如请求队列已满） | 只发给目标窗口，页面显示在状态栏 |
| `save-all-request` | `{ requestId }` | Go 轮流请求某个窗口保存其脏缓冲 | 只发给当前窗口；页面以 `ReportSaveAll` 回报 |
| `save-all-done` | `SaveAllSummary` | 所有窗口已回报或超时 | 只发给发起保存全部的窗口 |
| `close-requested` | 空对象 | 用户关闭有未保存修改的窗口，原生关闭已被阻止 | 只发给该窗口；页面弹保存 / 放弃 / 取消，处理完以 `closeWindow(true)` 关闭 |
| `file-trashed` | `{ path: string, name: string }` | 某窗口把文件移入回收站成功 | 只发给打开该文件的窗口；页面保留缓冲并显示“文件已移至回收站”，允许另存为 |

`DocUpdate`：`doc`（新文档，成功时）、`failure`（失败原因，页面保留旧内容并显示过期提示）、`seq`（窗口内递增，页面丢弃小于等于已应用值的更新）。

- 事件只是"有新请求"的提示，不是唯一投递渠道：请求留在 Go 侧队列里直到 `Ack`，事件丢了也不会丢请求。页面收到事件后按 `seq` 去重再处理。
- `doc-updated` 与 `Refresh` 可能交叠：页面按 `seq` 丢弃迟到的自动刷新结果；手动刷新以调用返回为准。
