# M6-3 验收记录：智能标点

> 对应 `docs/P3-高级工具需求.md` §3.3，验收项 P3-AC-07、P3-AC-08、P3-AC-14。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 开关 | 编辑菜单「智能标点」子菜单（一项 checkbox 与设置同步，默认关）+ 设置对话框「编辑」组复选框；两个入口写同一份 `smartPunctuation` 设置 |
| 输入时转换 | `EditorView.inputHandler` 逐键拦截 `"`、`'`、`.`、`-`，替换在按键自身的事务里，一次 Ctrl+Z 撤销输入本身 |
| 引号 | `"` 仅在前或后是 CJK 时转换：开括号/空白/行首出 `“`，其余 `”`；`'` 只在两个 CJK 之间转换，`don't` 等英文语境保持半角 |
| 省略与横线 | `...` → `…`（第四个 `.` 不再触发）；`--` → `–`，`--`+`-` 或已有 `–`+`-` → `—`；全行只有横线与空格的行（分割线、front matter 线）不转换 |
| 不触发场景 | IME 组合输入（`view.composing`）、粘贴、多字符输入、撤销重做、保护区域（代码/公式/front matter/HTML/链接地址）；关闭开关立即停止，不回改已有字符 |
| 共享保护判定 | `src/editor/protection.ts`：`protectedAt` = `protectedLineSet` + `inlineProtected`（行内代码、HTML、链接图片地址、autolink、行内公式）；`includeMath` 让数学工具排除公式——数学、智能标点与后续拼写检查用同一份判定（P3-AC-14） |
| 设置链路 | `appstate.Settings.SmartPunctuation *bool`（旧文件无字段默认 `false`）→ `SettingsView`/`SettingsChange` 加字段 → `SaveSettings` 持久化，变化时向所有窗口广播（打印视图除外） |

## 3. 原生验收

待用户在真实 Windows 11 窗口验收（开发服务器 5273）：

| 操作 | 预期 |
| --- | --- |
| 编辑 → 智能标点 → 启用智能标点 | 勾选生效，状态栏无错误；另一窗口的同名菜单同步勾选 |
| 输入 `他说"`、`他（"` | 分别出现 `”`（CJK 在前）与 `“`（开括号在前） |
| 英文上下文输入 `"`（如 `say "hi"`） | 保持半角 `"`，不转换 |
| `don't`、两个 CJK 之间输入 `'` | 前者保持半角，后者出 `’` |
| `...`、`....` | 三个点变 `…`，第四个点保留 |
| `a--`、`a---` | `a–`、`a—`；行首单独 `---` 不被转换 |
| 在 `` ` `` 代码、`$…$` 公式、链接地址里输入 `-`、`"` | 一律保持半角原样 |
| Ctrl+Z | 一次撤销把 `“`/`…`/`—` 连同触发它的按键一起撤销，不是两步 |
| 中文 IME 输入引号 | 不触发转换（IME 组合期跳过） |
| 关闭开关后再输入 `"`/`...`/`--` | 立即不再转换，已转换字符不回改 |
| 设置 → 编辑 → 智能标点 | 与菜单勾选态一致，重启后保持 |

## 4. 边界与未覆盖

- 转换只对新输入生效，不重写已有文档、不批量处理（P3 §3.3 已冻结）；粘贴、导入、撤销重做不触发。
- `'` 的转换要求两侧都是 CJK，`他'`、`'好`、英文所有格一律保持半角。
- `---` 行判定按「整行只有横线与空格」处理，包含其他字符的行正常按 `–`/`—` 规则转换。
- IME 组合期跳过依赖 `view.composing` 与 inputHandler 的组合输入路径；各输入法（微软拼音/搜狗等）行为以真实窗口验收为准。
- 拼写检查（M6-4）将复用 `protection.ts` 的同一份判定，本期先验 `protectedAt` 与 `mathProtected` 的一致性。
