# M5-8 验收记录：编辑辅助、主题菜单与 P2 总验收

> 对应 `docs/P2-效率与排版需求.md` §8、§11、§15，验收项 P2-AC-18、P2-AC-27、P2-AC-28、P2-AC-29、P2-AC-30、P2-AC-31。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 删除范围 | 编辑菜单新增子菜单：删除词、删除当前行、删除当前段落；只在编辑模式且源码编辑区有焦点时启用，无默认快捷键；每个命令一步撤销 |
| 换行符 | 子菜单显示当前文档换行 `LF` / `CRLF` / `混合`，提供转换为 LF/CRLF；转换不修改 LF 缓冲，标记未保存，第一次撤销先撤销转换；混合未转换保存写 CRLF，保存结果回填状态栏 |
| 空格与换行 | 清理行尾空格（保留 Markdown 两个空格硬换行、反斜杠硬换行、代码围栏与缩进代码）；确保文件末尾换行；无变化不标记脏、不产生撤销步骤 |
| 表情与符号 | 编辑菜单项显示非阻塞提示“按 Win+. 打开 Windows 表情面板”；不注册全局快捷键、不拦截 Win+. |
| 主题菜单 | 顶层“主题”位于“视图”和“帮助”之间，只含浅色、深色、跟随系统；与设置共用 `appearance`，所有窗口立即切换并持久化 |
| P2 总验收 | 扩展语法恶意样本、大表格渲染、搜索取消、P0/P1 自动回归与代表性原生抽查 |

## 3. 原生验收

环境：Windows 11 真实窗口；开发服务器 5273，调试端口 9222；窗口前台化后通过 `scripts/native-eval.mjs` 驱动 DOM 命令并读取状态。

| 操作 | 结果 |
| --- | --- |
| 菜单结构 | 顶层为文件、编辑、段落、格式、视图、主题、帮助；主题位于视图与帮助之间 |
| 主题菜单 | 深色项 `aria-checked=true`；两个窗口 `data-theme` 均为 `dark`、`color-scheme` 均为 `dark`；`settings.json` 的 `appearance` 写为 `dark`；设置对话框选中深色 |
| 恢复跟随系统 | 主题菜单选“跟随系统”后 `data-theme=light`、无固定主题属性；`settings.json` 回写 `system` |
| 删除当前行 | 首行被删，标题变为 `lf.md •`；`Ctrl+Z` 一次恢复首行并清除脏标记 |
| 删除范围焦点 | 菜单继承编辑器焦点时子项可用；编辑器未获焦时父项禁用并显示“先把光标放进源码编辑区” |
| LF → CRLF 并保存 | 转换后标题带 `•`、状态栏 `CRLF`；保存后文件 5 个 CRLF、0 个孤立 LF，状态栏显示 `CRLF` 与文件大小 51 B |
| CRLF → LF 并撤销 | 转换后状态栏 `LF`、标题带 `•`；编辑器内 `Ctrl+Z` 后恢复 `CRLF`、标题清除脏标记，文件未写盘 |
| 混合文件 | 打开显示“混合”；不转换直接保存后文件全部 CRLF（54 B），状态栏改显 `CRLF` |
| 行尾空格与末尾换行 | 三个行尾空格按硬换行保留为两个空格；反斜杠行保留反斜杠并去尾空格；代码围栏内空格保留；末尾无换行补一个换行，保存后文件字节符合预期 |
| Win+. 提示 | 编辑菜单点击“表情与符号”后状态栏显示“按 Win+. 打开 Windows 表情面板”，无对话框、无焦点抢占 |
| 大表格输入 | `table.md`（2000 行）进入编辑后可插入文本并标记脏，`Ctrl+Z` 恢复干净；CodeMirror 只渲染可见行，DOM 不全量展开 |
| P0/P1 抽查 | `math.md` 显示 5 个 KaTeX；`gfm.md` 显示 1 个表格与 2 个任务复选框；`mermaid.md` 显示 6 个 SVG，饼图与 `%%{init}%%` 按白名单拒绝 |
