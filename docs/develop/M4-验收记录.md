## 2. 已知边界

- P1-AC-05 的真实 Windows ACL / 只读目录拒绝未在本阶段重新做桌面操作；错误分支与 UI 保留缓冲已由自动测试覆盖。
- P1-AC-16 的多窗口“保存全部 + 同名文件冲突 + 未命名缓冲”组合需要在真实桌面连续操作系统对话框，本阶段只完成 Go 路由单测与单窗口原生验证，留待用户验收。
- P1-AC-19 的“除显式保存外不写盘”没有针对 P1 编辑/保存路径做文件哈希对比；现有只读证明来自 P0 的打开、扫描、渲染路径。
- 外部修改在预览模式下的滚动位置只做尽力保留；源码编辑模式会尽量恢复光标偏移，但没有自动断言。
- 保存全部在 5 分钟无响应或窗口关闭时记为未处理；超时后的迟到回报不会回写已发出的汇总（界面会在该窗口状态栏提示请求失效）。
