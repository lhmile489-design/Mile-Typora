# M5-5 验收记录：复制与粘贴扩展

> 对应 `docs/P2-效率与排版需求.md` §7，验收项 P2-AC-15、P2-AC-16。
> 自动验证与原生验收分开记录；无法脚本化的部分明确标为边界，不写成全部通过。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 拷贝图片（EDIT-05） | 编辑器图片语法或阅读/预览区选中的本地图片；Go 读取、解码 PNG/JPEG/GIF/WebP，统一转 PNG 写入剪贴板 |
| 粘贴（EDIT-06） | 编辑区 `Ctrl+V` 文本优先；只有图片时进入与插入图片相同的两阶段确认 |
| 粘贴图片 | 独立编辑菜单入口；图片转 PNG 存到文档 `assets/`，确认对话框显示完整目标 |
| 复制为纯文本（EDIT-07） | 源码选区由 Go 渲染并提取文字；阅读选区由页面按 DOM 提取；表格制表符、代码换行、图片替代文字 |
| 复制为 HTML（EDIT-09） | 清理后的 HTML + 纯文本回退写入同一个剪贴板 Item；源码与阅读选区都支持 |
| 简化格式（EDIT-10） | 只保留 `p`、`br`、`strong`、`em`、`ul`、`ol`、`li`、`blockquote`、`code`、`a[href]`；标题降为加粗段落，表格与图片移除 |

新增绑定：`ClipboardCopyPlainText`、`ClipboardCopyHTML`、`ClipboardCopyImage`、`ClipboardReadImage`，契约见 `docs/develop/接口契约.md`。

## 2. 自动验证

| 命令 | 结果 |
| --- | --- |
| `go test ./...` | 221 项通过，14 个包 |
| `bunx vitest run` | 305 项通过，19 个文件 |
| `bun run typecheck` | 通过 |
| `bun run build:web` | 生产构建通过（保持既有大于 500 kB 分包警告） |

覆盖点：

- Go 纯文本：标题、强调、链接标记去掉；表格单元格制表符、行换行；代码保留；图片替代文字保留；注释不进入结果。
- Go HTML：脚本、事件属性、样式、类名、`javascript:` 链接、远程/本地图片不进入片段；普通格式保留标题、表格、安全链接；简化格式只保留 keep-list，危险链接退化为文字。
- Go 图片：JPEG、GIF 转 PNG；阅读区 `mtres` 令牌只允许本窗口；远程地址拒绝；剪贴板 PNG 原样写入；剪贴板无图返回 `no_image`。
- 页面选区：Ctrl+A 的全页选区裁剪到正文；表格转制表符；KaTeX 取 TeX 源、Mermaid 取图源；只识别 `mtres.localhost` 图片。
- 页面命令：源码与阅读选区的纯文本/HTML/简化复制；编辑器与阅读区拷贝图片；`Ctrl+V` 文本优先与图片回退；菜单键盘焦点在鼠标打开后仍可用。

## 3. 原生验收

环境：Windows 11 真实窗口，`testdata/render/links.md` 与 `testdata/render/images.md`，开发服务器 5273，调试端口 9222。

| 操作 | 结果 |
| --- | --- |
| 编辑区全选 → 编辑 → 复制为纯文本 | 系统剪贴板为 `链接 / 跳到第二节 / 外部链接…`，无 `#`、`[]()`、`**` 等 Markdown 标记 |
| 编辑区全选 → 复制为 HTML 代码 | `HTML Format` 含 `<h1>`、`<p>`、安全 `<a href>`；无脚本、样式、类名；`javascript:` 链接退化为纯文字 |
| 编辑区全选 → 复制内容并简化格式 | 标题变 `<p><strong>`；无 `<h1>`、`<table>`、`<img>`、`style=`、`class=`、`javascript:` |
| 阅读区选中本地图片 → 编辑 → 拷贝图片 | 剪贴板含 `image/png` 与 `DeviceIndependentBitmap`；PNG 解码为 64×64，与原图一致 |
| 设置剪贴板文本 → 编辑区 `Ctrl+V` | 文本插入到光标处，状态栏保持编辑模式 |
| 设置剪贴板图片 → 编辑区 `Ctrl+V` | 出现确认对话框，显示完整目标 `testdata/render/assets/粘贴图片.png`；确认后文件写入，文档插入 `![粘贴图片](assets/%E7%B2%98%E8%B4%B4%E5%9B%BE%E7%89%87.png)` |

本次原生验收后已删除临时 `assets/粘贴图片.png` 与空目录并放弃未保存缓冲，仓库文件未改变。

## 4. 边界与未覆盖

- 阅读区选区的 HTML/简化复制由 `src/lib/clipboard.ts` 的 DOM 测试覆盖，本次原生只实测了源码选区；阅读区拷贝图片已原生实测。
- 剪贴板 HTML 在其他应用（Word、浏览器）中的渲染效果未逐一验收；本机只检查了 `HTML Format` 的结构与禁用内容。
- 超大图片的 20 MiB / 2500 万像素拒绝由 Go 测试覆盖；未在原生窗口构造超限样本。
- 未落盘文档粘贴图片的“先另存为”提示由菜单禁用与 Go `no_file` 覆盖，未做原生点击。
- 剪贴板同时含文本与图片时的文本优先由页面测试覆盖；原生只分别验证了纯文本和纯图片。
