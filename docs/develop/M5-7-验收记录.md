# M5-7 验收记录：视图模式、窗口与字数统计

> 对应 `docs/P2-效率与排版需求.md` §10，验收项 P2-AC-22、P2-AC-23、P2-AC-24、P2-AC-25、P2-AC-26。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 专注模式（F8） | 编辑模式淡化当前段落以外的行；阅读/预览禁用并提示 |
| 打字机模式（F9） | 编辑模式把当前行保持在视口约 40%；退出恢复正常滚动 |
| 全屏（F11） | 当前原生窗口全屏/退出，退出恢复原尺寸与位置 |
| 置顶 | 视图菜单复选项，只影响当前窗口 |
| 缩放 | 视图菜单显示百分比；`Ctrl+Shift+=` / `Ctrl+Shift+-` / `Ctrl+Shift+9`，50%–200%、10% 步进 |
| 窗口切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab` 按 MRU 在应用窗口间循环；不新建窗口；对话框打开时不切换 |
| 字数统计 | 只读对话框；选区或全文；中英文、代码、front matter、注释口径按 §10.6 |
| 状态栏显隐 | 视图菜单复选项；写入设置、跨窗口生效、重启保留；隐藏后提示浮动显示，标题保留未保存 `•` |

## 2. 自动验证

| 命令 | 结果 |
| --- | --- |
| `go test ./...` | 233 项通过，14 个包 |
| `bunx vitest run` | 327 项通过，20 个文件 |
| `bun run typecheck` | 通过 |
| `bun run build:web` | 生产构建通过（保持既有大于 500 kB 分包警告） |

覆盖点：

- 字数：CJK 每字 1 词、拉丁/数字/下划线连续段 1 词、代码 `__init__` 保留、front matter 与注释不计、字符数含/不含空白、段落数。
- 视图服务：缩放夹取到 50%–200%，MRU 正反向切换，单窗口无操作；设置保存后 `settings-changed` 跨窗口通知。
- 页面：F8/F9 阅读模式提示、编辑模式勾选、专注淡化、F11/缩放调用绑定、`Ctrl+Tab` 调用、字数统计对话框、状态栏隐藏与设置保存。

## 3. 原生验收

环境：Windows 11 真实窗口；`testdata/render/math.md` 与 `links.md` 两个窗口；开发服务器 5273，调试端口 9222。

| 操作 | 结果 |
| --- | --- |
| 两窗口间 `Ctrl+Tab` | 焦点从 math.md 切到 links.md；页面 keydown 收到组合键，未使用原生菜单加速器 |
| `Ctrl+Shift+Tab` | 焦点从 links.md 切回 math.md |
| `F11` | 当前窗口进入全屏，Go 返回 `fullScreen: true`；再次 F11 恢复 `false` 与原尺寸 |
| 视图菜单置顶 | `alwaysOnTop: true`；再次点击恢复 `false` |
| `Ctrl+Shift+=` | 缩放从 100% 到 110%，Go 返回 `zoom: 1.1` |
| `Ctrl+Shift+9` | 缩放恢复 100%（补了 Shift+9 产生 `(` 的键值映射） |
| F8 | 编辑区 31/32 行淡化，当前段落正常 |
| F9 | 光标移到文末后滚动容器 `scrollTop` 从 0 到 577px，当前行约 40% 视口 |
| 字数统计 | math.md 显示字符 213、非空白 176、词 100、段 10 |
| 隐藏状态栏 | 当前窗口状态栏消失，另一窗口同步隐藏；重启应用后仍隐藏 |
| 恢复状态栏 | 视图菜单重新勾选后显示，设置恢复为 `true` |

## 4. 边界与未覆盖

- 原生只验证了两个窗口的 MRU 切换；三个及以上窗口的顺序由 Go 单测覆盖。
- 对话框打开时 `Ctrl+Tab` 被页面统一拦截由自动测试覆盖，未做原生弹窗组合。
- 字数统计的选区与注释口径由 Go 测试覆盖；原生只统计全文。
- 隐藏状态栏后的浮动提示未在原生构造保存失败；代码路径与页面测试覆盖。
- 全屏与系统多显示器/最大化组合由 mygo 恢复逻辑处理，未单列验收。
