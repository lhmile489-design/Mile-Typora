# M6-4 验收记录：拼写检查

> 对应 `docs/P3-高级工具需求.md` §3.4，验收项 P3-AC-09、P3-AC-10、P3-AC-14。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 开关 | 编辑菜单「拼写检查」子菜单（一项 checkbox 与设置同步，默认关）+ 设置对话框「编辑」组复选框；两个入口写同一份 `spellCheck` 设置 |
| 词典 | `typo-js@2.0.0`（Hunspell 风格）+ 包内自带 `en_US.aff/.dic`，经 Vite `?url` 引入、`fetch` 取内容交给 `new Typo("en_US", aff, dic)`；不联网、不调系统检查器、只查英文（CJK 永不标记） |
| 懒加载 | `loadDictionary()` 只在首次打开设置时跑一次（模块级 promise 缓存），失败返回 `null` 不抛错，词典缺失时检查器安静地保持关闭；源码区 `contentAttributes` 固定 `spellcheck="false"` 关掉 WebView2 原生检查器 |
| 自绘波浪线 | StateField 持有 `Decoration.mark`（`cm-spell-error`，CSS `underline wavy var(--danger)`）；ViewPlugin 在 `docChanged`/`viewportChanged` 后 400 ms 去抖扫可见视口，单次最多 5000 个英文词，滚动与换文档触发重扫；关闭设置时显式 `field.init(() => Decoration.none)` 清标记 |
| 检查范围 | 只扫正文/标题/列表文本；跳过围栏与缩进代码、行内代码、行内/块级公式、front matter、链接图片地址、HTML 标签/注释、Markdown 标记——复用 `protectedAt` 共享判定（P3-AC-14），并新增 `protectedMask` 批量版本让范围扫描一次预计算 |
| 右键菜单 | 自绘页面级浮层，仅在右键落在被标单词上时出现；至多 5 条建议 + 「忽略本次」（会话级 Set，不持久化）；点建议是一次可撤销编辑，点空白、Esc 或换词关闭 |
| 设置链路 | `appstate.Settings.SpellCheck *bool`（旧文件无字段默认 `false`）→ `SettingsView`/`SettingsChange` 加字段 → `SaveSettings` 持久化，变化时向所有窗口广播（打印视图除外） |

## 3. 原生验收

待用户在真实 Windows 11 窗口验收（开发服务器 5273）：

| 操作 | 预期 |
| --- | --- |
| 编辑 → 拼写检查 → 启用拼写检查 | 勾选生效，词典后台加载，无卡顿；另一窗口的同名菜单同步勾选 |
| 输入 `this wrod is wrong` | `wrod` 出现波浪下划线，`this`/`is`/`wrong` 不标 |
| 输入中文（含中英混排） | 中文与 CJK 词一律不标 |
| 在 `` ` `` 代码、`$…$` 公式、front matter、链接地址里写错词 | 一律不标 |
| 右键点 `wrod` | 页面浮层出现建议（如 `word`/`ward`/`rod`）与「忽略本次」 |
| 点一条建议 | 错词被替换为建议，Ctrl+Z 一步撤销 |
| 点「忽略本次」 | 该词不再标，直到重启应用（不写盘） |
| 在普通正文、空白处或正确单词上右键 | 不出现拼写浮层，也不弹系统菜单 |
| 滚动、换文档、停止输入约 400ms 后 | 视口内错词重新标记 |
| 关闭开关 | 所有波浪线立即消失，右键浮层不再出现 |
| 设置 → 编辑 → 拼写检查 | 与菜单勾选态一致，重启后保持 |

## 4. 边界与未覆盖

- 只查英文；不提供自定义词典、不持久化忽略、不批量修正、不做语法检查（P3 §3.4 已冻结）。
- 「忽略本次」只在本进程内有效，不写设置文件；重启后该词恢复标记。
- 单次视口扫描上限 5000 词，超长粘贴只标记前 5000 个；滚动后重扫覆盖新视口。
- 词典懒加载首次打开约数百毫秒；加载失败（离线构建、安装损坏）时检查器安静关闭，不拖垮编辑器。
- 建议由 typo-js 的编辑距离算法产出，数量至多 5 条；无建议时菜单只显示「忽略本次」。
- 真实键入、IME 输入与保护区域行为待用户桌面验收。
