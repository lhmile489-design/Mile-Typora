# M6-1 验收记录：导入 HTML 与 DOCX

> 对应 `docs/P3-高级工具需求.md` §3.1，验收项 P3-AC-01、P3-AC-02、P3-AC-03、P3-AC-04。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 文件菜单“导入…” | 文件菜单新增导入入口，位于删除与偏好设置之间；导入进行中禁用重复触发 |
| HTML 转换 | Go 侧 `internal/markdown/importhtml.go`：标题、段落、列表、引用、代码围栏、GFM 表格、链接、hr；脚本、样式、表单、iframe 丢弃；本地 / data / file 图片只保留替代文字并警告 |
| DOCX 转换 | Go 侧 `internal/markdown/importdocx.go`：`archive/zip` + `encoding/xml` 读取正文、标题样式、加粗 / 斜体 / 删除线、列表、表格、超链接；图片变文字占位；宏、页眉页脚、脚注、外部关系不读取 |
| 新缓冲 | 当前窗口没有文件且不脏时直接载入；否则新建窗口，通过 `ReadyInfo.startText` / `startName` 移交文本；原文件不修改 |
| 格式损失 | 独立“导入完成”对话框按类别列出警告，不阻塞导入 |
| 限制 | 10 MiB 输入、DOCX 相关 XML 解压合计 32 MiB、2048 条目、压缩比 100:1、路径穿越拒绝、8 秒超时、HTML 仅 UTF-8 |
| 绑定 | 新增 `WindowService.ImportDocument`、`contract.ImportResult`、`ReadyInfo.startText/startName`；`transport.importDocument()` 返回 imported / cancelled / failed |

## 2. 自动验证

| 命令 | 结果 |
| --- | --- |
| `go vet ./...` | 通过 |
| `go test ./...` | 246 项通过，14 个包 |
| `bun run typecheck` | 通过 |
| `bunx vitest run` | 338 项通过，21 个文件 |
| `bun run build:web` | 通过，保留既有大分包警告 |

覆盖点：

- HTML：标题、段落、强调、列表、引用、代码围栏、GFM 表格、链接、远程图片；脚本、事件属性、`file:` 图片被丢弃并产生警告。
- DOCX：标题样式、加粗、普通段落、列表、表格；`../` ZIP 条目拒绝；宏与页眉不进入缓冲；图片占位。
- 服务：空窗口直接导入且源文件字节不变；取消与错误扩展名/超限不生成结果；已有文件窗口移交新窗口并设置 `startText` / `startName`。
- 页面：文件菜单导入入口、导入完成对话框、空窗口导入后标题与脏标记、新窗口移交时当前文档不变。

## 3. 原生验收

环境：Windows 11 真实窗口，开发服务器 5273，调试端口 9222。

| 操作 | 结果 |
| --- | --- |
| 文件菜单 | 显示“导入…”且可用；导入进行中禁用 |
| 系统文件选择对话框 | 由 Go 打开 HTML/HTM/DOCX 过滤器；对话框本身无法可靠脚本化（D-T17），完整点击流程待用户桌面操作 |
| 新窗口移交 | 由 Go 单测覆盖 `ReadyInfo.startText` 路径；原生未逐步点击 |

## 4. 边界与未覆盖

- 系统文件选择对话框与真实 Word/WPS DOCX 样本的点击导入未做原生脚本化验收，需用户桌面操作。
- DOCX 合并单元格、复杂编号、脚注、页眉页脚只按冻结范围降级或丢弃，不承诺还原。
- HTML 复杂嵌套 div/span 只解包为文本；合并单元格拆为普通单元格。
- 图片不落盘是冻结取舍；HTML 远程图片保留地址但阅读器不请求，DOCX 图片为文字占位。
