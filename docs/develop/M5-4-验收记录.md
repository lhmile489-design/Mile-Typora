# M5-4 验收记录：链接操作与图像

> 对应 `docs/P2-效率与排版需求.md` §6.1、§6.2，验收项 P2-AC-07、P2-AC-14、P2-AC-17。
> 记录分开写“自动验证”和“原生验收”；不可脚本化的部分明确标为待桌面验收，不写成通过。

## 1. 交付内容

| 能力 | 实现 |
| --- | --- |
| 链接地址读取 | 行内 `[文字](地址 "标题")` 与引用式 `[文字][标签]`；忽略图片语法；只扫描光标所在行 |
| 编辑地址 | 行内链接只替换目标，保留文字与标题；引用式链接只改文末定义行 |
| 移除链接 | 还原链接文字，不删除引用定义行 |
| 复制链接地址 | 写入系统剪贴板，不访问网络 |
| 菜单入口 | 格式 → 链接操作子菜单；无链接时三项禁用并说明原因 |
| 插入图片 | 选择 PNG/JPEG/GIF/WebP，确认后复制到文档同目录 `assets/`，插入 URL 编码的相对路径 |
| 更换图片 | 光标位于图片语法内时可用，只替换目标并保留替代文字；不删除旧文件 |
| 重名与覆盖 | 选择时生成 `名称-1.ext`；复制使用独占创建，目标已存在即失败 |
| 授权 | 有工作区根时文档必须在根内；单文件模式以确认对话框作为本次写入授权；确认期间根或路径变化会拒绝写入 |
| 未落盘文档 | 菜单禁用并提示先另存为；Go 侧同时返回 `no_file` |

新增绑定：`WindowService.PickImage`、`CopyImage`、`CancelImage`，契约见 `docs/develop/接口契约.md`。菜单栏新增一层子菜单，点击、悬停、左右方向键与 Escape 均可用。

## 2. 自动验证

| 命令 | 结果 |
| --- | --- |
| `go test ./...` | 213 项通过，14 个包 |
| `bunx vitest run` | 295 项通过，18 个文件 |
| `bun run typecheck` | 通过 |
| `bun run build:web` | 生产构建通过（保持既有大于 500 kB 分包警告） |

覆盖点：

- 纯变换：行内链接编辑地址保留标题、相邻链接可分别命中、引用式链接只改定义、移除链接保留文字、图片不被识别为链接、图片插入与替换。
- Go：选择阶段不写盘；确认后复制到 `assets/`；中文文件名生成 `assets/%E5%9B%BE.png`；重名使用 `图-1.png`；令牌一次性；取消不创建目录；文档在工作区外拒绝；确认期间目标被占用不覆盖；确认期间工作区改变返回 `out_of_scope`。
- 页面：格式子菜单编辑地址、复制地址、移除链接；插入图片显示完整目标路径、确认后写入 Markdown；更换图片替换路径并保留旧文件。

## 3. 原生验收

环境：Windows 11 真实窗口，`testdata/render/links.md`，编辑模式。

| 操作 | 结果 |
| --- | --- |
| 格式 → 链接操作子菜单 | 三项可见；光标在链接内时可用 |
| 编辑地址… → `https://native.example` → 保存 | 源码变为 `[链接文字](https://native.example)`，链接文字保留 |
| 复制链接地址 | PowerShell `Get-Clipboard` 读回 `https://native.example` |
| 移除链接 | 源码变为 `链接文字` |
| 格式菜单图片项 | 已落盘文档中“插入图片…”可用；“更换图片…”在光标不在图片语法内时禁用 |

未完成 / 边界：

- 系统“插入图片”文件对话框属于 Windows DirectUI，`SendKeys` 无法稳定注入路径（D-T17）。图片选择到复制确认的完整点击流程**待用户桌面验收一次**；Go 复制逻辑与页面确认流程已由自动测试覆盖。
- 本次原生只验证链接操作；图片替换的原生点击流程同在上述待验收范围。
- 四种图片格式的文件头与像素校验沿用 `internal/resource` 既有测试（PNG/JPEG/GIF/WebP），M5-4 服务测试以 PNG 走通复制路径。
