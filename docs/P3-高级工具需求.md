## 1. 建议默认与待确认项

### 1.1 建议默认（随本文确认后冻结）

| 决策 | 建议默认 | 理由 |
| --- | --- | --- |
| 导入格式 | **HTML / HTM 与 DOCX 首批交付**；Go 侧离线转换，生成新缓冲，不覆盖输入文件 | HTML 复用已有 `golang.org/x/net/html`；DOCX 用标准库 `archive/zip` 与 `encoding/xml` 解析 OOXML，不引入第三方文档转换库 |
| 导入图片 | **不落盘**：HTML 只保留 http(s) 图片地址，本地 / data / file 图片改成替代文字；DOCX 内嵌图片改成文字占位并警告 | 新缓冲没有目录，无法安全写 assets；避免 data URI、越权读取与假路径 |
| 数学工具 | **公式模板、定界符转换与当前公式检查**，不做 CAS、求解、符号计算、实时编辑预览或截图识别 | 复用现有 KaTeX 与纯文本变换；不引入数学引擎与网络 |
| 智能标点 | **默认关闭**，只作用于新输入，不追溯修改；只在 CJK 语境转换引号，英文缩写不处理 | 避免静默改文；用户可随时关闭并依赖普通撤销 |
| 拼写检查 | **页面内自绘检查器 + 内置 en-US 词典**（`typo-js@2.0.0`，BSD-3-Clause，懒加载），默认关闭；不联网、不检查中文 | WebView2 原生拼写无法按区域排除代码 / 公式且 mygo 未暴露开关 API；自绘可复用 CodeMirror 装饰与现有排除规则 |
| 代码工具 | **围栏代码块内的缩进整理、制表符 / 空格转换与语言名小写**，不做语言级格式化、不执行代码 | 可控、可测试、无第三方格式化依赖 |
| 开发者工具 | **诊断模式默认关闭，开启或关闭需重启生效**；`Shift+F12` 只在诊断模式下打开当前窗口检查器；不开启远程调试端口 | mygo v0.9.0 的 `PageOptions.DevTools` 在窗口创建时决定；重启切换是当前 API 下唯一可验证的路径 |
| 诊断开关持久化 | 写入设置，默认 `false`；模式生效后所有新窗口启用检查器，关闭需重启 | 用户明确开启后无需每次重开；默认关闭；设置页持续显示风险说明 |

### 1.2 需要用户确认的取舍

1. **导入图片**：是否接受 M6-1 不落盘任何图片？HTML 的 http(s) 图片保留地址但不会被阅读器加载；DOCX 内嵌图片变成“图片未导入”文字占位。若要求导入图片，需另定“另存为时落盘 / 要求先保存”的流程与授权边界。
2. **拼写检查依赖**：是否接受新增前端依赖 `typo-js@2.0.0`（约 733 KB 解包，含 en-US 词典，BSD-3-Clause）并只检查英文？不引入依赖就必须放弃拼写检查或改用不可控的系统能力。
3. **诊断模式**：是否接受“开启或关闭需重启生效”，以换取生产默认完全关闭开发者工具？

## 3. 详细需求

### 3.1 导入 HTML 与 DOCX（FILE-15）

- 文件菜单新增“导入…”，接受 `.html` / `.htm` / `.docx`（大小写不敏感），文件选择对话框按扩展名过滤；不提供多选与拖拽导入。
- 输入上限 10 MiB。HTML 只接受 UTF-8（含 BOM），非法编码拒绝；DOCX 必须是有效 ZIP + OOXML 且包含 `word/document.xml`，否则按不支持类型拒绝。
- DOCX 额外限制：解压后 `document.xml`、`styles.xml`、关系文件合计不超过 32 MiB；条目总数不超过 2048；拒绝绝对路径、`..` 路径穿越、加密条目与超过 100:1 压缩比的条目；含 `vbaProject.bin` 或 OLE 对象时只警告、不读取、不执行。
- 转换结果是**新的未保存缓冲**：当前窗口为空时直接载入；当前窗口已有文档时先新建窗口再载入。缓冲命名为 `导入-<原文件名去扩展名>`，不写入磁盘；输入文件不被修改、移动或删除。
- 转换超时 8 秒，超时或失败不生成缓冲、不留下部分结果。

**HTML 映射**

- 块级：`h1`–`h6` → 标题；`p`、`div` → 段落；`ul` / `ol` / `li` → 列表（嵌套最多两层）；`blockquote` → 引用；`pre` / `code` → 围栏代码块（`language-xxx` 作为语言标签）；`table` / `tr` / `th` / `td` → GFM 表格；`hr` → `---`。
- 行内：`strong` / `b` → `**`；`em` / `i` → `*`；`del` / `s` → `~~`；`code` → 行内代码；`a` 的 http / https / mailto 地址 → `[文字](地址)`，其他协议只保留文字；`br` → 行内换行。
- 图片：http(s) 地址保留为 `![alt](url)`，阅读与预览不会请求远程图片；相对路径、本地绝对路径、`data:`、`file:` 一律替换为替代文字并警告。
- 丢弃并警告：`script`、`style`、`iframe`、`object`、`embed`、`template`、`form` / 控件、内联事件属性、`class`、`style`、CSS、字体、颜色、注释、页眉页脚与分页信息。

**DOCX 映射**

- 读取 `word/document.xml`、`word/styles.xml`、`word/_rels/document.xml.rels` 与超链接关系；不读取页眉、页脚、脚注、尾注、批注、修订历史、图表、SmartArt、文本框、OLE 对象与宏。
- 段落样式只映射常见标题样式（`Heading 1`–`Heading 6` 及 `Title`）到 Markdown 标题；其余段落按普通段落输出。
- 行内只保留加粗、斜体、删除线与 `w:t` 文本；字体、字号、颜色、主题、缩进、对齐、分页全部丢弃并汇总警告。
- 列表读取 `w:numPr` 的有序 / 无序属性，最多缩进两层；编号值按出现顺序重排为 `1.` 或 `-`，不保证与原编号一致。
- 超链接只保留关系目标中的 http / https / mailto 地址；其他协议只保留文字。
- 表格转换为 GFM 管道表格；合并单元格拆为普通单元格并警告。
- 内嵌图片不提取、不写 `assets/`，转换为 `[图片：原文件名]` 文字占位并警告；不读取外部图片关系。

**通用**

- 导入结果对话框按类别列出警告与数量，不展示原始正文；警告不阻塞导入。
- 转换在 Go 侧完成并只输出 Markdown 文本；前端不执行导入内容，不使用 `innerHTML` 写入导入结果，不获得源文件目录的隐式授权。
- 新增绑定 `ImportDocument`，返回文本、建议文件名与警告；错误码包含 `cancelled`、`unsupported_type`、`too_large`、`encoding`、`import_failed`、`timeout`。

### 3.2 数学工具（EDIT-17）

- 编辑菜单新增“数学工具”子菜单，只在源码编辑模式启用；每个命令是一步可撤销编辑，无默认快捷键。
- 子菜单项（有界清单，不随 Typora 继续扩张）：
  - 行内公式：选区包裹为 `$...$` 或解包既有行内公式；无选区时插入 `$公式$` 并把光标放在中间。
  - 块级公式：选区包裹为 `$$` 块，无选区时插入空块并把光标放在块内；与 `Ctrl+Shift+M` 的现有公式块命令行为一致。
  - 分数、根号、上标、下标：插入 `\frac{}{}`、`\sqrt{}`、`^{}`、`_{}`，占位内容选中。
  - 矩阵：插入 `\begin{pmatrix} ... \end{pmatrix}`，默认 2×2，使用 `&` 与 `\\` 分隔。
  - 分段函数：插入 `\begin{cases} ... \end{cases}`。
  - 多行对齐：插入 `\begin{aligned} ... \end{aligned}`。
  - 求和、积分、极限：插入 `\sum_{}^{}`、`\int_{}^{}`、`\lim_{}`，占位内容选中。
  - 定界符转换：光标在唯一公式内时，在 `$...$` / `\(...\)` / `$$...$$` / `\[...\]` 之间转换；行内与块级互换时整理必要换行；跨公式、跨代码或不在公式内时拒绝并提示。
  - 检查当前公式：光标在公式源码内时用现有 KaTeX（`trust: false`、`maxExpand: 1000`、16 KiB 上限）解析，显示“公式有效”或 KaTeX 的真实错误；不在公式内时提示。
- 行内公式、定界符转换与检查公式要求光标位于公式内或选区只覆盖一个公式；代码围栏、行内代码、front matter、注释内禁用并说明原因。
- 复用现有 `Snapshot → ParagraphEdit` 纯变换与一次 dispatch；新增 `inMath` 编辑器上下文，菜单使能与 `inTable` / `inLink` 一致。
- 不新增公式编辑对话框、源码内实时预览控件或自动修复；阅读 / 预览继续用现有 KaTeX 渲染。
- 明确不做：符号计算、求解方程、化简、单位换算、公式 OCR、截图转公式、手写识别、宏管理、`\label` / `\ref` 管理。

### 3.3 智能标点（EDIT-18）

- 编辑菜单新增“智能标点”子菜单，含一个与设置同步的复选项，默认关闭；只影响开启之后的新输入，不扫描或重写已有正文。
- 输入规则（只在普通正文、光标处生效）：
  - `"`：仅当前一个字符或后一个字符是 CJK 时转换。前一字符为空、空白、`([{（【“‘` 之一时插入 `“`，否则插入 `”`。
  - `'`：仅当前后均为 CJK 字符时插入 `‘` / `’`；英文缩写（`don't`）与所有英文语境保持半角。
  - 连续输入三个半角句点 `...` 转换为 `…`。
  - 连续输入两个半角连字符 `--` 转换为 `–`；三个连字符 `---` 转换为 `—`，但行首仅含空白的 `---`（分隔线 / front matter）不转换。
- 跳过区域：围栏代码块、缩进代码、行内代码、行内公式、块级公式、front matter、HTML 块与注释、链接 / 图片地址、自动链接；输入法组合期间不处理。
- 粘贴、导入、撤销 / 重做不触发转换；转换与本次输入合并为普通撤销粒度，一次 `Ctrl+Z` 撤销该次输入，不产生额外历史项。
- 关闭开关后立即停止转换；已在文档中的字符不还原；不做“转换整个文档”的批量命令。
- 英文弯引号、CJK 句读（。、，；：？！）、`「」`、`《》`、自动配对与分数 / 箭头等符号不在 P3 范围。

### 3.4 拼写检查（EDIT-21）

- 设置新增“拼写检查”开关，编辑菜单提供同一复选项；默认关闭，只对源码编辑区启用，阅读与预览不检查。
- 实现为页面内自绘检查器：新增懒加载模块 `src/editor/spellcheck.ts`，用 CodeMirror `Decoration.mark` 画波浪下划线；不影响文档文本、保存格式与撤销历史。
- 词典固定使用 `typo-js@2.0.0`（BSD-3-Clause，解包约 733 KB，含 en-US 词典），只在首次开启时懒加载；不联网、不下载语言包、不调用系统或云端拼写服务。
- 语言范围只支持英文（en-US）；纯中文文档不产生标记，中英混排只检查英文单词。不做中文、其他语言、自定义词典与语言切换界面。
- 检查范围：普通正文、标题与列表文字；跳过围栏代码、缩进代码、行内代码、行内 / 块级公式、front matter、链接与图片地址、HTML 标签 / 注释、Markdown 标记字符。
- 性能：输入停止约 400ms 后检查当前可见视口，每次最多 5000 个英文词；滚动或切换文档后重新检查可见区域；不阻塞输入，不扫描整篇大文档。
- 右键菜单：只有右键命中拼写标记时显示页面内浮层，最多 5 个建议词与“忽略本次”；选择建议替换为一步可撤销编辑，“忽略本次”仅当前会话有效。其他位置维持现有无右键菜单行为，不恢复 WebView2 的 Reload / Back / Forward / Inspect。
- 编辑器显式设置 `spellcheck="false"`，避免 WebView2 原生红线与自绘标记叠加。
- P3 不做用户词典、持久忽略列表、批量修正、语法检查与拼写统计。

### 3.5 代码工具（PARA-08）

- 段落菜单新增“代码工具”子菜单，只在光标位于围栏代码块内或选区覆盖围栏代码块时启用；无默认快捷键。
- 子菜单项：
  - 缩进整理（2 空格）：把块内正文行的行首制表符按下一 4 列制表位展开，再统一为 2 空格倍数；公共前导缩进保留。
  - 缩进整理（4 空格）：同上，统一为 4 空格倍数。
  - 转换为制表符缩进：只把行首缩进列数为 4 的倍数的行转换为制表符；不可整除的行保持原样并在状态栏提示未转换行数。
  - 代码块语言名小写：只改写围栏 info 串第一个 token 为小写；其他属性原样保留；未知语言不改写。
- `makefile` / `make` 代码块禁用“缩进整理”（Makefile 配方行必须保留制表符），菜单项显示原因；“转换为制表符缩进”仍然可用。
- 只处理围栏代码块正文行，不改围栏字符、围栏长度、语言标签（语言名小写项除外）与代码内容中的行内空白；不处理缩进代码块。
- 选区跨围栏边界时拒绝执行并提示；每个命令一步撤销，无变化不标记脏。
- 不做语言级格式化、语法树重排、自动补全、运行、编译、测试或执行任何代码；不引入 Prettier / gofmt 等外部格式化器。
- 与 M5-8 的行尾空格清理正交：代码块内部行尾空格不由本工具处理，避免破坏代码内容。

### 3.6 开发者工具（VIEW-17）

- 设置新增“诊断模式”开关，默认关闭，附风险说明：开启后，本机页面内容与脚本状态可被查看和修改；不开启远程调试端口。开关保存后显示“重启后生效”。
- 因为 mygo v0.9.0 在窗口创建时决定 `PageOptions.DevTools`，诊断模式**开启或关闭后需要重启应用生效**；这是唯一冻结的生效模型，不做会话内重新武装或按新窗口即时切换。
- 诊断模式开启时，应用创建的普通窗口使用 `DevToolsEnabled`；关闭时使用 `DevToolsDisabled`。打印视图、导出临时窗口始终禁用。
- 视图菜单新增“开发者工具”，`Shift+F12` 与菜单调用同一命令；只在诊断模式开启时有效，否则显示提示“先在设置中开启诊断模式并重启”，不打开检查器。
- 绑定方法 `OpenDevTools` 用 `mygo.CallerWindow(ctx)` 定位调用窗口，拒绝打印窗口；Go 侧再次校验诊断模式，不能只依赖前端禁用。
- 不设置 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`、不监听远程调试端口、不接受外部 CDP 连接；应用自身不写入任何调试端口配置。
- 检查器只影响当前窗口；打开后用户自行关闭检查器窗口。关闭诊断模式不即时关闭已打开检查器，重启后生效。
- 已知行为：诊断模式开启的窗口会恢复 WebView2 自带的 F5 / Ctrl+P / Ctrl+F 等浏览器按键（与检查器同时启用）；这是该模式的明确代价，设置页风险说明中注明。

## 4. 设置与持久化

| 键 | 类型 | 默认 | 作用 |
| --- | --- | --- | --- |
| `smartPunctuation` | bool | `false` | 智能标点输入转换 |
| `spellCheck` | bool | `false` | 源码编辑区拼写检查 |
| `diagnosticMode` | bool | `false` | 下次启动是否启用开发者工具 |

- 三个键加入 `SettingsView` / `appstate.Settings`，保存后跨窗口通知；旧设置文件缺字段时按默认 `false` 读取。
- 诊断模式改变后提示“重启后生效”，不即时重建窗口。
- M6-4 新增依赖固定为 `typo-js@2.0.0`（BSD-3-Clause）；开工时写入 `decisions.md` 并更新锁文件，不引入 wasm、系统词典或云端接口。
- M6-2 / M6-3 的代码 / 公式 / URL / front matter 排除判定抽成一个共享行内保护模块，避免三套扫描器漂移；M6-4 必须复用它。

## 5. 验收基线（P3-AC）

| 编号 | 验收内容 | 通过标准 |

## 7. 安全与边界

- 导入不执行输入中的任何内容，不解析外部实体、不联网、不写入输入文件；HTML 与 DOCX 转换只在 Go 侧进行，只输出 Markdown 文本与警告，不把源文件路径写进用户可见错误之外的位置。
- DOCX 按 ZIP 条目流式读取并限制解压总量、条目数、压缩比与路径；宏、OLE、外部关系一律不读取。
- 拼写检查使用随包词典，不把正文发送到网络；检查器只读缓冲，不写文档；诊断模式不开放远程调试端口。
- 数学工具、智能标点、代码工具都只改当前缓冲，保持一步撤销与脏标记语义；三者共用同一行内保护判定，避免代码 / 公式 / URL 在不同功能中结论不一致。
- 诊断模式的风险说明必须在设置页可见，默认关闭；开启后 WebView2 自带浏览器按键的恢复属于已知代价。
- 所有新增界面文案禁止 emoji；图标只用 lucide-react 或系统符号。
- 本阶段不改变 P0–P2 的只读边界、远程图片策略、CSP、路径授权与保存格式规则。
