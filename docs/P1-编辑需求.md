# P1 基础编辑需求（M4-0，门禁 G5）

> 依据：PRD §10、§14 第 6 项、§15.2–15.6、§16.1，以及 2026-11-16 用户对四项关键取舍的选择。
> 本文是 P1 的需求与验收基线。用户确认后（G5）才能开始 M4-1 的代码；实现中若要改行为，先改本文并重新确认。

## 1. 已定决策

| 决策 | 结果 | 理由 |
| --- | --- | --- |
| 编辑方式 | **源码编辑 + 预览切换**（同一缓冲，`Ctrl+/` 切换） | P1 先保住保存、撤销、冲突闭环；所见即所得留到后续评估 |
| 保存编码 | **保留原格式**：已有文件保留原 BOM 与 LF/CRLF；新文件 UTF-8 无 BOM + LF | 不因编辑静默改写用户文件格式（PRD 10.2） |
| 外部变更冲突 | **保留本地编辑并提示**，提供重新载入 / 另存为 / 保留当前编辑；不自动覆盖 | PRD 10.3：未保存修改不得被自动刷新覆盖 |
| 查找替换 | **单次替换 + 全部替换**，各自是一次可撤销编辑；不支持正则 | 覆盖 P1 需求，范围与撤销粒度可测 |
| 自动保存/崩溃草稿 | P1 不做 | PRD 10.2 明确另行确定 |

## 2. P1 范围（命令编号沿用 PRD §15）

**文件**：FILE-01 新建、FILE-05 快速打开、FILE-07 保存、FILE-08 另存为、FILE-10 保存全部；FILE-02/03/04/06/18/19 的菜单入口；FILE-19 关闭需未保存保护。
**编辑**：EDIT-01 撤销、EDIT-02 重做、EDIT-03 剪切、EDIT-04 复制（P0 能力，P1 菜单）、EDIT-06 粘贴（纯文本）、EDIT-08 复制为 Markdown（仅源码编辑区）、EDIT-11 粘贴为纯文本、EDIT-12 选择（全选 / 当前行 / 当前段落）、EDIT-13/14 上移/下移行、EDIT-15 删除、EDIT-22 查找替换。
**段落**：PARA-01–04 标题与升降级、PARA-06 公式块、PARA-07 代码块、PARA-10 引用、PARA-11/12 有序/无序列表、PARA-13/14 任务列表与状态、PARA-15 列表缩进、PARA-16/17 上下插入段落、PARA-20 分割线。
**格式**：FORMAT-01 加粗、FORMAT-02 斜体、FORMAT-04 行内代码、FORMAT-05 删除线、FORMAT-07 超链接、FORMAT-10 清除样式。
**视图**：VIEW-06 源码/预览切换；P1 的视图菜单只含这一项。侧栏与状态栏仍走 P0 工具栏，按 PRD 15.6 其菜单入口属 P2，不提前做；设置入口按 FILE-18 进文件菜单。
**帮助**：关于（版本）、本产品快捷键说明。

**非目标（P1 不做）**：所见即所得、左右分栏、表格/脚注/警告框/TOC/图片粘贴与落盘、富文本或 HTML 粘贴、导出与打印、自动保存与崩溃恢复、正则替换、多光标、拼写检查、跨窗口撤销、P2/P3 的文件操作与视图模式。

## 3. 模式与状态模型

- 每个窗口一份编辑缓冲，状态：`reading`（P0 只读渲染）、`editing`（源码可编辑）、`preview`（编辑中的只读渲染），三者共享同一缓冲。
- 默认打开文件仍进入 `reading`。工具栏/菜单/`Ctrl+/` 进入编辑；再按 `Ctrl+/` 在 `editing` 与 `preview` 间切换。是否停留在编辑模式按窗口记忆（本进程内）。
- 脏状态：缓冲内容与最近一次成功加载/保存的内容不同即为“未保存”。窗口标题追加 `•`，状态栏显示“未保存”，并保持只读徽标之外的保存状态；不依赖颜色单一表达。
- 未保存内容不因切换文件、切换目录、打开新请求、外部刷新或切换模式而丢失。
- 只读保证更新为：**除显式的保存 / 另存为 / 保存全部外，P1 不写用户文件**；打开、刷新、切换、预览、关闭都不写盘。
- 编辑模式只作用于源码区；预览区与阅读区永远不可直接编辑。任务复选框在编辑模式的源码里通过命令修改，预览中仍只读。

## 4. 文件生命周期

### 4.1 新建（FILE-01）

- `Ctrl+N`：当前窗口空白时复用该窗口；非空白窗口新建原生窗口（与 FR-02 一致）。
- 新缓冲名为“未命名-1/2/…”，不立即写盘；首次 `Ctrl+S` 打开另存为对话框。
- 新缓冲默认源码编辑模式，UTF-8 无 BOM、LF。

### 4.2 快速打开（FILE-05）

- `Ctrl+P` 打开浮层：输入框 + 结果列表（最多 50 条），按文件名/相对路径做大小写不敏感的包含匹配。
- 目录模式：范围是当前目录根内已扫描的 Markdown；单文件模式：范围是最近记录中的文件。
- 回车打开、上下键选择、Esc 关闭；打开前走未保存保护；不触发全文搜索。

### 4.3 保存（FILE-07）/ 另存为（FILE-08）/ 保存全部（FILE-10）

- 保存只在有路径时直接写；无路径转另存为。跳过“另存为”并直接覆盖必须由用户明确选择路径。
- 另存为成功后，窗口缓冲切换到新路径，原文件不变；新路径成为该窗口的授权读取范围（仍需经过正常路径检查）。
- 保存全部：遍历本应用所有窗口的脏缓冲，逐个保存；无路径的逐个询问另存为；汇总“已保存 / 失败 / 未处理”，部分失败时失败窗口保持脏状态。
- 保存成功后更新脏状态与冲突基线；保存失败保留缓冲、脏状态和原因，不显示成功提示。
- 保存过程中禁止重复触发同一缓冲的保存；失败后可重试。

### 4.4 关闭与退出（FILE-19）

- 关闭窗口、关闭标签式切换（切换文件/目录）、退出应用时，脏缓冲必须给出 **保存 / 放弃 / 取消** 三选一；取消则中止本次操作。
- 关闭应用时逐窗口处理；“保存全部”失败或取消则不退出。
- 放弃修改只丢弃内存缓冲，不删除磁盘文件；关闭窗口后不留下可恢复草稿（P1 非目标）。
- 未修改的窗口直接关闭，不弹确认。

## 5. 保存格式与可靠性

- 编码：只编辑 UTF-8 文件。已有文件保留原 BOM（有则保留、无则不添加）；新建文件无 BOM。
- 换行：已有文件保留 LF/CRLF；混合换行按 P0 检测结果视为 CRLF，保存时统一 CRLF（在状态栏/保存前提示一次）。新文件 LF。
- 内容：保存写回编辑器缓冲的完整源码，不做额外格式化；不修改未涉及的行。
- 原子写：同目录创建临时文件，写入并落盘后替换目标；保留原文件的权限/ACL（Windows 使用替换语义，而不是删除后重建）；失败时清理临时文件，原文件保持。
- 保存前检查磁盘指纹（大小、修改时间、内容 SHA-256 基线）；不一致进入 §6 冲突流程。
- 文件被外部删除后保存：提示“文件已被删除”，提供“重新创建 / 另存为 / 取消”，不静默重建。
- 不做自动保存、备份副本、崩溃恢复（P1 非目标）。

## 6. 外部变更与多窗口冲突

- 编辑中（脏）发现外部写入/删除：
  - 不自动刷新、不覆盖缓冲。
  - 正文顶部提示“文件已在外部修改”，操作：**重新载入磁盘版本**（放弃本地编辑，需确认）/ **另存为** / **保留当前编辑**（关闭提示，保存时按冲突处理）。
- 保存时的冲突判断：磁盘当前内容哈希 ≠ 本窗口加载/上次保存的基线哈希：
  - 说明“磁盘上的文件已被其他窗口或程序修改”。
  - 操作：**另存为**（默认）/ **覆盖磁盘**（二次确认，明确会丢失另一方修改）/ **取消**。
- 同一文件在多个窗口编辑：先保存的窗口更新磁盘；后保存的窗口必然检测到基线变化并进入冲突流程，不得静默覆盖。
- 根目录被移除或文件不可读：保留缓冲，允许另存为抢救；不自动关闭窗口。
- 外部删除在编辑中先显示提示条（重新载入 / 另存为 / 保留当前编辑）；用户选“保留当前编辑”后再次保存时，按 §5 的删除询问处理（重新创建 / 另存为 / 取消）。
- 外部变更在缓冲干净时：编辑/预览中可直接载入新内容（保持光标位置尽力而为），阅读模式沿用 P0 自动刷新与过期条。

## 7. 编辑命令行为

### 7.1 撤销 / 重做

- `Ctrl+Z` / `Ctrl+Y` 只作用于当前窗口缓冲；撤销历史按窗口隔离。
- 每个用户级操作是一步：一次粘贴、一次格式切换、一次段落转换、一次全部替换各为一步；不做字符级拆分。
- 撤销回到干净基线时，脏标记消失；重做再次标记。

### 7.2 文本命令

- 剪切/复制/粘贴使用系统剪贴板；粘贴按纯文本插入（不执行 HTML）。剪贴板失败明确提示。
- 删除：删除当前选区；无选区删除光标后一个字符（行尾则合并下一行）；不删除磁盘文件。
- 上移/下移行：`Alt+↑/↓` 移动当前行或选中行块，保持选区跟随；文件首/尾不越界。
- 复制为 Markdown：仅源码编辑区可用，复制源码选区；预览/阅读区无法可靠映射时提示“请在源码模式复制”，不猜造片段。

### 7.3 选择（EDIT-12）

- 全选：当前缓冲全文（`Ctrl+A`）。
- 当前行：光标所在行；当前段落：以空行分隔的块。后两项无默认快捷键，仅菜单。
- 选择命令不修改内容。

### 7.4 段落命令

- 标题：当前段落或选中段落转换为 1–6 级；`Ctrl+=`/`Ctrl+-` 在 1–6 级内升降，不越界。
- 段落：去掉块前缀，转换为普通段落；只影响块标记，不删正文。
- 列表：有序/无序/任务列表互相转换时保留文本；任务状态命令切换 `- [ ]` / `- [x]`，可撤销。
- 列表缩进：选中行整体增减一级缩进（2 或 4 空格按现有块判断），不改其他块。
- 引用、公式块、代码块、分割线：在光标处插入或包裹当前块；公式块用 `$$` 围栏，代码块用三反引号并可选择语言（Mermaid 作为语言使用 P0 图表渲染）。
- 上下插入段落：在当前块上方/下方插入空行与可编辑段落，光标进入新段落。

### 7.5 格式命令

- 加粗/斜体/删除线/行内代码：有选区时包裹或去除标记；无选区时插入成对标记并把光标放中间。
- 行内代码需正确处理内容中的反引号（用足够长的反引号围栏）。
- 超链接：有选区时把选区作为链接文字；无选区插入 `[链接文字](https://)` 并选中占位文字；链接地址仍受 P0 安全策略约束。
- 清除样式：只移除 P1 认识的格式标记，保留文字内容；不删除链接目标文字之外的内容。

### 7.6 查找替换（EDIT-22）

- 沿用 P0 查找条，编辑模式下增加替换输入与“替换 / 全部替换”。
- 匹配规则与 P0 一致：字面匹配、拉丁字母不区分大小写、中文按原样；不支持正则。
- 单次替换：替换当前命中并跳到下一个；全部替换：替换缓冲区所有命中，作为一次可撤销编辑。
- 替换仅作用于当前窗口的源码缓冲；预览/阅读模式下替换入口禁用并说明。
- 无命中、空查询、零长度匹配不产生修改。

## 8. 菜单与快捷键

- P1 增加“文件 / 编辑 / 段落 / 格式 / 视图 / 帮助”菜单；菜单项、工具栏和快捷键调用同一命令与启用条件。
- 编辑类命令仅在编辑器可编辑且获得焦点时生效；焦点在文件树、预览、按钮或对话框时禁用。文件树的 Delete 不删除磁盘文件（P1 没有文件删除命令），编辑器 Delete 只改文本。
- P1 新增快捷键：`Ctrl+N`、`Ctrl+P`、`Ctrl+S`、`Ctrl+Shift+S`、`Ctrl+Z`、`Ctrl+Y`、`Ctrl+X`、`Ctrl+V`、`Ctrl+Shift+C`、`Ctrl+Shift+V`、`Alt+↑/↓`、`Ctrl+/`、`Ctrl+1–6`、`Ctrl+0`、`Ctrl+=`、`Ctrl+-`、`Ctrl+Shift+M`、`Ctrl+Shift+K`、`Ctrl+Shift+Q`、`Ctrl+Shift+[`、`Ctrl+Shift+]`、`Ctrl+Shift+X`、`Ctrl+B`、`Ctrl+I`、`Ctrl+Shift+反引号`、`Alt+Shift+5`、`Ctrl+K`、`Ctrl+\`。
- 无默认快捷键的菜单项（选择当前行/段落、保存全部、上/下插入段落、分割线、任务状态、列表缩进等）只通过菜单触发，不凭记忆补映射。
- `Ctrl+S` 在 P1 变为真实保存；P0 的“仅支持阅读”提示移除。`Ctrl+W`/关闭按钮在有未保存修改时先弹三选一。
- 只读/无文档时编辑类命令禁用；菜单项显示禁用原因（无文档、只读、无选区）。

## 9. 预览与安全

- 预览复用 P0 的 Go 渲染管线与白名单清理；编辑缓冲内容不写盘即可预览。
- 预览中的公式、Mermaid、图片、链接、任务框行为与 P0 一致；链接点击仍走 P0 的确认/阻止策略。
- 原始 HTML 在预览中仍转义为文本；不允许编辑模式引入脚本、事件属性、iframe、用户 SVG 或远程图片。
- 预览渲染失败局部降级，不阻塞源码编辑；保存不受渲染结果影响。

## 10. 界面状态与错误

- 标题：`文件名 • — Mile Typora`；未命名缓冲显示“未命名-N •”。
- 状态栏：保存状态（已保存 / 未保存 / 保存中）、编码（UTF-8 / UTF-8 BOM）、换行；错误带图标+文字。
- 保存中禁用保存入口并显示进行中；失败显示原因与“重试”。
- 冲突/外部变更提示条遵循 DESIGN §8.7，提供明确按钮，不自动关闭。
- 对话框（未保存、冲突、覆盖确认）默认焦点在“取消”，Esc 取消，焦点进入并归还。

## 11. 验收条目（P1-AC）

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| P1-AC-01 | 打开文件后按 `Ctrl+/` 进编辑、切预览、再切回 | 同一缓冲、内容与光标/滚动位置不丢；预览与 P0 渲染一致 |
| P1-AC-02 | `Ctrl+N` 新建，不保存直接关闭 | 空白窗口复用/非空白新开；未写磁盘；关闭弹保存/放弃/取消 |
| P1-AC-03 | 新建缓冲 `Ctrl+S` | 打开另存为；保存后标题/路径/编码/换行正确，磁盘内容与缓冲一致 |
| P1-AC-04 | 打开带 BOM 与 CRLF 的文件，编辑保存 | 保存后仍有 BOM 与 CRLF；内容未涉及部分不变 |
| P1-AC-05 | 保存失败（只读目录或 ACL 拒绝） | 保留缓冲与未保存标记，显示原因，可重试；无成功提示 |
| P1-AC-06 | 编辑后切换文件/目录、关闭窗口、退出 | 每次都弹保存/放弃/取消；取消中止；放弃不改磁盘 |
| P1-AC-07 | 两个窗口编辑同一文件，先后保存 | 后保存窗口发现磁盘已变；默认另存为；覆盖需二次确认；无静默覆盖 |
| P1-AC-08 | 编辑中在外部修改/删除文件 | 脏缓冲不自动覆盖；提示重新载入/另存为/保留；删除后选保留再保存，按删除询问提供重新创建或另存为；干净缓冲在编辑/预览模式可载入新内容且不丢光标位置 |
| P1-AC-09 | 撤销/重做各类操作 | 每个用户级操作一步；回到干净基线时脏标记消失；不跨窗口撤销 |
| P1-AC-10 | 10 个 P1 编辑命令逐个执行 | 行为符合 §7，均可撤销；只读/预览模式下禁用 |
| P1-AC-11 | 段落命令（标题、列表、引用、任务、代码、公式、分割线、上下插入） | 只改块标记或插入正确源码；正文不丢；可撤销 |
| P1-AC-12 | 格式命令（粗斜体、行内代码、删除线、链接、清除样式） | 选区/无选区行为符合 §7.5；行内代码处理反引号；可撤销 |
| P1-AC-13 | 查找替换：单次、全部、无命中、大小写 | 匹配规则同 P0；全部替换一步撤销；不修改预览/阅读模式 |
| P1-AC-14 | 选择全选/当前行/当前段落，上移/下移行，删除 | 选区与移动范围正确，首尾不越界，文件不被删除 |
| P1-AC-15 | 菜单、快捷键、工具栏触发同一命令 | 行为、启用条件一致；无默认快捷键的命令只在菜单；焦点在文件树、预览或按钮时编辑命令不生效，文件树 Delete 不改磁盘 |
| P1-AC-16 | 保存全部含失败、未命名缓冲与同一文件多窗口 | 逐个汇总；失败保持脏状态；同一文件在两个窗口都有修改时，保存全部走冲突流程（另存为/覆盖确认/取消），不静默覆盖；不承诺跨文件原子性 |
| P1-AC-17 | 预览/阅读模式尝试编辑与替换 | 无法修改内容；提示明确；任务框只读 |
| P1-AC-18 | 编辑含公式、Mermaid、图片、恶意 HTML 的文档 | 预览仍安全渲染，局部失败可降级，正文可编辑保存 |
| P1-AC-19 | P0 回归：只读打开、刷新、目录、设置、外观 | P0 行为不退化；除显式保存外无文件写入 |
| P1-AC-20 | 快速打开（目录/单文件模式） | 匹配范围正确、键盘可用、打开前走未保存保护 |
| P1-AC-21 | 编辑中根目录被改名/移除或文件变为不可读 | 窗口不自动关闭，缓冲与脏状态保留，另存为可成功落盘；不静默重建原路径 |

## 12. 技术前置与风险

- 编辑器内核在 M4-1 前定稿并写入 `docs/decisions.md`；候选为 CodeMirror 6（撤销、选区、行操作成熟，增加依赖与包体积）或原生 textarea + 自管撤销（零依赖，但行操作与撤销分组需自写）。本需求不预先承诺实现库。
- 原子保存与 ACL 保留需要 Windows 文件替换语义；M4-2 先做保存失败/冲突测试，再接编辑命令。
- 预览需要 Go 侧新增“渲染内存中的源码”能力（不读盘），沿用现有渲染管线与白名单；M4-1 定义契约并更新 `docs/develop/接口契约.md`。
- 未保存保护会改变 P0 的关窗/切文件流程；M4-2 必须覆盖 P0 回归（P1-AC-19）。
- P1 仍不做自动保存；若用户后续要求，另立需求与门禁。

## 13. 与 P0 的边界变化

- P0 “任何写用户文件的代码都是缺陷”在 P1 调整为：**只有用户显式保存/另存为/保存全部才写文件**；其余路径保持只读。
- 关闭窗口的“直接退出”改为脏缓冲三选一；无修改时与 P0 相同。
- `Ctrl+S` 从提示变为保存；`Ctrl+W` 在脏缓冲时不再直接关闭。
- 只读徽标在编辑模式改为模式标识（编辑/预览），阅读模式仍显示只读。
