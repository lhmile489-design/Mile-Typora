## 3. 扩展语法规范

### 3.1 表格（PARA-05）

- 持久化语法为 GFM 管道表格；首行表头、第二行分隔行，列对齐写在分隔行。
- “插入表格…”弹出小对话框选择行数、列数（1–20，默认 2 列 2 行），生成表头与分隔行，光标进入第一个单元格。
- 子菜单：在上方插入行、在下方插入行、在左侧插入列、在右侧插入列、删除当前行、删除当前列、删除表格、左对齐、居中、右对齐。
- 行列命令只在光标位于表格内时启用；对齐命令作用于当前列，重写整列分隔符。
- 单元格内的 `\|` 转义、行内格式和中文原样保留；表格命令不进入围栏代码块、公式块、front matter。
- 表格编辑只改源码文本，每次命令是一步可撤销编辑。

### 3.2 脚注（PARA-19）

- 引用写作 `[^标签]`，定义写作 `[^标签]: 内容`；定义可出现在文末或文中，渲染时统一汇总到文末脚注区。
- 插入脚注：优先使用下一个未占用的数字标签（`[^1]`、`[^2]`…），在光标处插入引用，并在文末追加定义行，光标进入定义内容。
- 已有脚注：命令跳到对应定义；标签保持用户原文，不自动重排或重编号。
- 阅读渲染：上标序号、文末脚注列表、引用与定义双向跳转；缺失定义时引用按原文显示，不报错。
- 脚注内容照常经过行内渲染与白名单清理，不能借此注入 HTML 或脚本。
- 脚注结构由渲染器生成，白名单增量为：`sup`、`li[id]`、`div.footnotes`、`a.footnote-ref`、`a.footnote-backref`；id 只接受渲染器生成的 `fn:`/`fnref:` 前缀，文档不能自带 id。返回链接文字用“返回”，不使用 emoji 或字体符号。
- 如果实现选择自绘脚注渲染器，类名与 id 形态必须在 `docs/decisions.md` 固定；不得放开任意 `id`、`class` 或 `role` 属性。

### 3.3 警告框（PARA-09）

- 语法为引用块首行 `> [!TYPE]`，TYPE 仅接受 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`；写入统一大写，读取不区分大小写。
- 子菜单按五种类型插入；选中内容时把选中块包成对应引用块，无选区时插入空警告框。
- 渲染为带类型标签和语义色的提示块；颜色复用现有 info / accent / warn / danger 令牌，不新增配色，不使用 emoji。类型与令牌映射固定为：NOTE=info，TIP=accent，IMPORTANT=warn，WARNING=warn，CAUTION=danger；同色类型靠标签文字区分。
- 块内允许列表、代码、链接等普通块；未知类型（如 `[!FOO]`）保持普通引用并显示原文，不报错。
- 警告框结构必须由渲染器生成，文档中的原始 `<div class="alert">` 仍按文本转义，不能冒充提示块。
- 渲染结构固定为 `div.alert.alert-<type>[data-type=<type>]` + `p.alert-title` + 内容；白名单新增类名 `alert`、`alert-note`、`alert-tip`、`alert-important`、`alert-warning`、`alert-caution`、`alert-title`，`data-type` 只允许五种枚举值；标题用文字标签和 CSS 边框/底色，不引入 SVG 或 emoji。
- 实现方式是 goldmark 的引用块 AST 识别与自定义渲染器，不是让 bluemonday 放行文档 HTML。

### 3.4 正文目录（PARA-21）

- 独占一段的 `[TOC]` 在渲染时替换为本文标题列表，链接指向现有标题锚点；点击在文内滚动，不打开新窗口。
- 标题层级 h1–h6 全部收录，按层级缩进；重复标题使用现有唯一 id 规则。
- 源文件只保留 `[TOC]` 标记；标题增删改后重新渲染即更新，不向源文件写入静态目录。
- 没有标题时 `[TOC]` 不输出内容；多个 `[TOC]` 各自生成一份。
- 目录条目不进入左侧文件树/大纲，二者互不替代。
- 渲染结构固定为 `nav.toc` + `ol.toc-list` + `a.toc-link`；白名单新增 `nav` 与这三个类名。链接 `href` 只能是渲染器为本文档生成的标题 id，文档自带的 id 不进入目录。
- 实现需先收集标题再回填 `[TOC]` 占位；多个 `[TOC]` 各自生成一份；500 个标题上限同时约束 TOC 与大纲，超出时保留前 500 条并显示截断提示。

### 3.5 下划线（FORMAT-03）

- 持久化语法为 `<u>文字</u>`，仅放行精确的 `<u>` 与 `</u>` 两个无属性标签；大小写不敏感，带任何属性或其他标签一律按原始 HTML 转义。
- `Ctrl+U` 切换下划线：有选区时包裹或去除，无选区时插入成对标签并把光标放在中间。
- 预览渲染为真正的 `<u>` 元素；清除样式同时移除下划线标记并保留文字。
- 放行逻辑在渲染器层：RawHTML 片段去掉空白后必须完全等于 `<u>` 或 `</u>`（大小写不敏感），才输出原始标签；`<u class="x">`、`<u/>`、`<u >` 等一律继续转义。`u` 元素加入 bluemonday 白名单，且不带任何属性。
- 除 `<u>`/`</u>` 外的原始 HTML 行为不变：仍转义为文本展示。

### 3.6 注释（FORMAT-06）

- 持久化语法为标准 HTML 注释 `<!-- 内容 -->`，可单行或独占多行。
- 阅读/预览中完整注释整段隐藏；源码编辑区原样可见。注释不参与阅读/预览渲染后的文内查找、目录、字数统计和导出正文；源码编辑器 `Ctrl+F` 仍可命中注释源码，这是预期行为。
- 只有“整个节点是以 `<!--` 开头、以 `-->` 结尾的完整注释”才隐藏；未闭合的 `<!--`、或注释与普通文本同段混排时，注释节点按转义文本显示，普通文本照常渲染。
- 插入注释：有选区时包裹选区，无选区时插入 `<!-- -->` 并把光标放在中间。
- 渲染器完全不输出注释节点，不生成 DOM 注释；注释内容永远不执行、不参与渲染。

### 3.7 链接引用（PARA-18）

- 语法为 `[文字][标签]` 与定义行 `[标签]: 地址 "可选标题"`；阅读沿用 P0 CommonMark。
- 插入引用式链接：生成 `ref-1`、`ref-2`… 未占用标签，把定义追加到文末（与前文空一行），保持标签一致。
- 编辑地址同时支持行内链接与引用式链接；引用式链接修改定义行，不改所有引用点。
- 移除链接把 `[文字](地址)` 或 `[文字][标签]` 还原为文字；不删除可能仍被其他引用使用的定义行。
- 地址仍受协议白名单与文档路径授权约束；`javascript:`、`data:`、`file:` 等定义在渲染时被清理。

### 3.8 YAML Front Matter（PARA-22）

- 文档开头 `---` 到 `---`/`...` 的块继续按 P0 只读折叠展示；P2 只增加源码编辑入口，不解析 YAML、不执行内容、不提供结构化表单。
- “插入文档元信息”在文档顶部没有 front matter 时插入 `---`、`title:`、`---`，光标放在 `title:` 后；已有块时把光标移到块内，不重复插入。
- 段落命令继续避开 front matter；导出 HTML/PDF 不输出折叠的元信息块。

### 3.9 清除样式对 P2 新语法的范围

P1 的清除样式只处理行内格式；P2 扩展后行为固定如下：

| 语法 | 清除样式行为 |
| --- | --- |
| `<u>文字</u>` | 移除 `<u>`/`</u>`，保留文字 |
| 行内注释 `<!-- 内容 -->` | 不处理；注释不是视觉样式，需删除请直接编辑源码 |
| 警告框 `> [!TYPE]` | 不处理块结构；块内行内格式仍可清除 |
| 脚注引用与定义 | 不处理结构；定义内容中的行内格式可清除 |
| 链接引用定义 | 不处理定义行；链接文字中的行内格式可清除 |
| 表格分隔行、`[TOC]`、front matter | 不处理结构；表格单元格与 front matter 内容不参与清除样式 |

## 4. 文件操作（M5-1）

通用规则：

- 移动到、删除、打开文件位置、在侧边栏中显示只对已落盘文档启用；未命名缓冲没有磁盘文件，菜单项禁用并显示原因。
- 当前焦点在文件树或文档列表且选中某个文件时，移动到、属性、删除作用于选中文件；否则作用于当前文档。打开文件位置与在侧边栏中显示始终作用于当前文档。
- 文件树焦点下按 Delete 触发与菜单相同的“移入回收站”确认；编辑器焦点下 Delete 仍只删除文本。任何情况下都不直接永久删除文件。

### 4.1 移动到…（FILE-09）

- 通过目录选择对话框选择目标目录，文件名保持不变；目标目录与当前目录相同则不操作。
- 目标已存在同名文件时中止并提示，不覆盖、不自动改名。
- 请求窗口有未保存修改时先走保存/放弃/取消；同一文件在其他窗口有未保存修改时中止，提示先保存。其他窗口的脏状态读取自既有 `setEditState` 上报；状态未知时按脏处理。
- 同盘使用重命名；跨盘使用“复制到目标临时文件 → 校验 SHA-256 → 替换目标 → 删除源文件”，任一步失败保留源文件并清理临时文件。
- 成功后更新所有打开该文件的窗口路径、标题、监听与最近记录；文件树刷新；阅读位置尽量保留。
- 用户选择的目标目录视为本次移动的显式授权；移出当前工作区根后，新路径仍作为该窗口的文档路径授权用于读取与监听，但不再属于原目录搜索/文件树范围。
- 未命名缓冲禁用；未落盘文档没有可移动的源文件。

### 4.2 删除…（FILE-14）

- 默认移至回收站，确认对话框显示文件名与“移至回收站”，不使用永久删除。
- 请求窗口或其他窗口有未保存修改时先处理或中止；不静默丢弃缓冲。
- 使用 mygo `Shell.TrashItem`；回收站不可用时显示失败原因，文件保持原位，绝不改为永久删除。
- 成功后所有打开该文件的窗口进入“文件已移至回收站”状态：保留内存内容，允许另存为；最近记录移除；文件树刷新。
- 未命名缓冲禁用；文件树选中文件时按 §4 通用规则作用于选中项。

### 4.3 属性…（FILE-11）

- 只读对话框展示：名称、完整路径、大小、编码（UTF-8 / UTF-8 BOM）、换行（LF/CRLF/混合）、修改时间、只读属性。
- 不提供修改系统属性、权限或时间戳的入口。
- 未落盘文档显示“尚未保存”，路径与修改时间为空。

### 4.4 打开文件位置…（FILE-12）

- 在 Windows 资源管理器中定位并选中当前已落盘文件；未落盘文档禁用并说明原因。
- 调用失败时显示提示，不影响文档状态。

### 4.5 在侧边栏中显示（FILE-13）

- 目录模式：展开当前文件的全部上级节点，滚动到文件并选中。
- 目录已打开但当前文件不在根内：确认后以文件所在父目录作为新工作区（替换当前根），当前文档与缓冲保持不变；取消不改变现有根。
- 单文件模式：先确认“打开文件所在目录作为工作区？当前文档保持不变”，确认后以父目录为根打开工作区并定位文件；取消不改变现有状态。
- 打开目录失败时保留当前文档与视图，显示原因。
- 未命名缓冲禁用并说明“文档尚未保存”。

## 5. 左侧视图与目录搜索（M5-2）

### 5.1 三种视图

- 左侧支持文件树、文档列表、大纲三种视图；每窗口记住当前选择（本进程内，不写入设置），默认文件树。
- 切换视图不改变当前文档、滚动位置或未保存缓冲。
- 大纲：显示当前文档 h1–h6，按层级缩进；点击滚动到对应标题；编辑时在停止输入约 300ms 后按源码更新，预览/阅读按渲染结果更新。
- 文档列表：当前目录递归 Markdown 平铺列表，自然排序；重名文件显示相对路径；点击打开走未保存保护。单文件模式没有目录根：菜单项与快捷键提示“未打开目录”，并提供“打开所在目录并列出”确认入口，确认后打开父目录再切换；取消保持当前视图。
- 文件树：保留现有层级、展开状态与当前文件选中；`Ctrl+Shift+3` 切回。
- 快捷键：`Ctrl+Shift+1` 大纲、`Ctrl+Shift+2` 文档列表、`Ctrl+Shift+3` 文件树；视图菜单提供同一入口与勾选状态。
- `Ctrl+Shift+L` 显示/隐藏侧边栏沿用现有命令，视图菜单补入口；视图菜单另增“显示预留侧栏”复选项（无快捷键），与工具栏开关调用同一命令；窄窗口自动收起的规则不变。

### 5.2 目录搜索（VIEW-05）

- 搜索当前已授权目录的 Markdown 文本内容与文件名，字面匹配、拉丁字母不区分大小写、中文原样；不支持正则。
- 结果按文件分组，显示文件名、相对路径、命中行片段与数量；片段按纯文本渲染，禁止 `innerHTML` 拼接文档内容。
- 点击打开文件前走未保存保护（保存/放弃/取消），与文档列表一致；打开后阅读/预览模式用该搜索词执行文内查找并定位首个命中，编辑模式按源码行/列定位。前端只回传相对路径，Go 侧仍经 pathguard 规范化并确认在授权根内。
- 搜索可取消（按钮与 Esc）；新搜索取消旧搜索；迟到结果丢弃。
- 容量上限：最多 500 条命中、200 个文件；跳过大于 10 MiB 的文件与二进制文件；达到上限显示“结果已截断”。
- 只访问当前授权根，不跟随重解析点越界；单文件模式提示“未打开目录”，提供“打开所在目录并搜索”，确认后打开父目录再搜索。
- 搜索在 Go 侧执行，不阻塞主线程；取消后释放扫描。

## 6. 格式扩展（M5-4）

### 6.1 链接操作（FORMAT-08）

- 子菜单：编辑地址…、移除链接、复制链接地址。
- 光标位于行内或引用式链接内时启用；编辑地址打开小输入框，确认后只改目标地址，保留链接文字与标题。
- 复制链接地址写入系统剪贴板文本；不访问网络。
- 没有链接时菜单项禁用并说明原因。

### 6.2 图像（FORMAT-09）

- “插入图片…”选择本地 PNG/JPEG/GIF/WebP；确认后复制到文档同目录 `assets/`，目录不存在则创建。
- 首次为某文档创建或写入 `assets/` 时，确认对话框显示完整目标路径；该授权只覆盖本次资源文件，不扩大文档读取范围。
- 目录模式下文档必须位于当前授权根内，否则禁用图片落盘并提示；单文件模式的确认对话框同时构成对文档同目录 `assets/` 的临时写入授权。
- 目标重名时自动使用 `名称-1.ext`、`名称-2.ext`；不覆盖已有文件。
- 插入相对路径 Markdown 图片，路径做 URL 编码；图片仍经 `mtres` 协议与文件头校验加载。
- 单图上限沿用 20 MiB / 2500 万像素；超限或格式不支持时拒绝并提示，不插入链接。
- 未落盘文档先要求另存为，再允许复制资源。
- “更换图片…”对光标所在图片执行同一复制策略并替换链接；不删除旧图片文件。
- 不下载远程图片、不启用图床、不在后台写入任何文件。

## 7. 复制与粘贴（M5-5）

### 7.1 拷贝图片（EDIT-05）

- 在阅读/预览中选中已允许加载的本地图片时启用；编辑器内光标位于图片语法时也作用于该图片。
- 通过 Go 读取本地文件，PNG/JPEG/GIF/WebP 统一转成 PNG 后写入剪贴板；JPEG 用标准库 `image/jpeg`、GIF 用 `image/gif`、WebP 用 `golang.org/x/image/webp` 解码，再用 `image/png` 编码。像素/大小上限沿用 20 MiB / 2500 万像素，解码失败显示原因。
- 被阻止的远程图片或未授权路径不能借此加载；复制失败显示原因，不修改文档。

### 7.2 复制为纯文本（EDIT-07）

- 阅读区或源码区有选区时可用；去掉标题、列表、引用、强调、链接等 Markdown 标记，保留可读文字与段落分隔。
- 表格按单元格文字展开：单元格之间用制表符，行之间用换行；代码块保留代码文本；图片保留替代文字。
- 只写剪贴板，不修改文档。

### 7.3 复制为 HTML 代码（EDIT-09）

- 有选区时把选区渲染为清理后的 HTML 片段，写入剪贴板 `text/html` 并提供 `text/plain` 回退。
- 通过 mygo `Clipboard.Write(transfer.Data)` 在同一个 Item 中同时写入 `transfer.HTML` 与 `transfer.Text`；不得退化为只写 HTML 或只写文本。
- 片段不含脚本、事件属性、样式、远程资源；本地图片不内嵌，保留占位或省略；注释不进入片段。
- 源码区按选区对应源码渲染；无法可靠映射时不猜造片段，提示改用预览/阅读选择。

### 7.4 复制内容并简化格式（EDIT-10）

- 剪贴板同时写入简化 HTML 与纯文本；同样使用 `Clipboard.Write(transfer.Data)` 的双格式写法。简化 HTML 只保留 `p`、`br`、`strong`、`em`、`ul`、`ol`、`li`、`blockquote`、`code`、`a[href]`。
- 标题降为段落并保留加粗；图片、表格、样式、类名、脚本全部移除；链接地址仍受协议白名单约束。

### 7.5 粘贴（EDIT-06）

- `Ctrl+V` 有文本时按纯文本粘贴（沿用 P1）；只有图片时走图片粘贴。
- 图片粘贴：统一转为 PNG 存入 `assets/`，每次落盘前显示目标路径确认；未落盘文档先要求另存为。
- 剪贴板同时有 HTML、文本与图片时，`Ctrl+V` 按纯文本粘贴；“粘贴图片”菜单入口显式走图片流程。
- 剪贴板同时有 HTML 与文本时按文本粘贴，不执行 HTML；P2 不做 HTML→Markdown 富文本转换。
- “粘贴图片”提供独立菜单入口，行为同上。

## 8. 编辑辅助（M5-8）

### 8.1 删除范围（EDIT-16）

- 子菜单：删除词、删除当前行、删除当前段落；只在编辑器有焦点时启用。
- 删除词：向前删除光标前一个词；拉丁字母/数字/下划线连续串为一个词，CJK 每字为一个词。
- 删除行：删除光标所在整行及行尾换行；文件最后一行不越界。
- 删除段落：删除以空行分隔的当前块及其分隔空行；不误删相邻块。
- 每个命令是一步可撤销编辑；菜单不分配默认快捷键。

### 8.2 换行符（EDIT-19）

- 子菜单显示当前文档换行：`LF`、`CRLF` 或 `混合`；提供“转换为 LF”“转换为 CRLF”。
- 转换作用于整个缓冲，标记为未保存，保存时才写盘；一次转换是一步撤销。
- 混合换行在状态栏显示“混合”；不转换直接保存时按 P1 规则统一写为 CRLF，保存后状态显示 CRLF。用户可先转换为 LF 以改变保存结果。
- 保存仍按窗口当前选择的换行写回，P1 的格式保留规则不变。

### 8.3 空格与换行（EDIT-20）

- “清理行尾空格”：删除行尾空格与制表符；但行尾恰好两个及以上空格构成的 Markdown 硬换行保留为两个空格；反斜杠硬换行不破坏；代码块内不处理。
- “确保文件末尾换行”：文件末尾没有换行时补一个；有多个空行时收敛为一个换行；不修改正文其他内容。
- 每个命令一步撤销；无变化时不标记脏、不产生撤销步骤。

### 8.4 表情与符号（EDIT-23）

- 菜单项显示“按 Win+. 打开 Windows 表情面板”的非阻塞提示，不在应用中注册全局快捷键，不拦截 `Win+.`。
- 编辑焦点下系统面板输入按普通文本进入缓冲；阅读/预览模式不启用该提示。

## 9. 导出与打印（M5-6）

### 9.0 打印样式与打印视图

当前应用没有打印样式，P2 必须新增独立的打印 CSS/打印文档，并满足：

- 隐藏工具栏、左右侧栏、状态栏、查找条、菜单与焦点高亮；只输出正文。
- 正文取消 860px 居中限制，按纸张宽度排版；`max-height` 与 `overflow` 恢复为可见。
- 标题不与后续正文分离；短表格、图片、公式、Mermaid 不跨页截断；长表格允许断行且表头跨页重复（`thead { display: table-header-group; }`）。
- 图片、公式、Mermaid 最大宽度 100%，不超出页宽。
- 打印内容来自独立打印视图，而不是直接在编辑器页面打印。打印视图由渲染管线产物组装：已清理正文、静态 MathML、已渲染并清理的 Mermaid SVG、内联样式；应用外壳不得出现在打印产物中。
- 打印视图可以是隐藏/离屏 mygo 窗口加载导出 HTML，也可以是等价的隔离容器；必须重新处理 CSP、图片路径（data URI 或重新注册的 `mtres`）和超时。M5-6 实测后把方案写入 `docs/decisions.md`。

### 9.1 导出 HTML（FILE-16）

- 导出单文件 `.html`：内联设计令牌对应的打印样式、正文 HTML、代码高亮样式；`lang="zh-CN"`，标题为文档名。
- 公式导出为 MathML 或等价静态结构；Mermaid 导出为已渲染的内联 SVG；本地图片转为 data URI；远程图片、被阻止资源不请求，替换为占位说明。
- 内嵌图片总量上限 20 MiB；超过上限时省略超出部分并列出警告，不生成半截文件。
- 不包含脚本、事件属性、iframe、用户 SVG；链接保留但不在导出时访问。
- 导出使用独立的导出清理器，不复用页面 bluemonday 白名单：正文节点来自已清理的渲染产物；MathML 只保留固定元素/属性子集；Mermaid SVG 只接受渲染器生成并经 DOMPurify 清理的节点；`data:image/(png|jpeg|gif|webp);base64` 只允许出现在 `img.src`，其他 `data:` 仍禁止；导出器不引入第三方 HTML。
- 导出模板自身的内联样式是固定字符串，不接受文档提供的 style/class。
- 默认文件名 `<文档名>.html`，通过保存对话框选择位置；写入使用原子替换，取消不写文件。
- 未落盘文档可导出当前缓冲，默认名“未命名.html”。

### 9.2 导出 PDF（FILE-16）

- 使用 mygo `Page.PrintToPDF`，在 §9.0 的专用打印视图上生成，A4 纵向、四边 0.6 英寸、打印背景；输出完整文档，不包含工具栏、侧栏、状态栏或编辑器界面。
- 专用打印视图可以是隐藏/离屏窗口加载导出 HTML，或等价的隔离容器；不得直接打印当前编辑器页面。M5-6 实测后把选定方案记录到 `docs/decisions.md`。
- 打印样式处理分页：标题不与正文分离、表格表头跨页重复、长表格可断行、图片与 Mermaid 不超出页宽、公式不截断。
- 默认文件名 `<文档名>.pdf`，保存对话框选择位置；生成失败或超时（30 秒）显示原因，不留下部分文件。
- 未落盘文档可导出当前缓冲；导出期间显示进行中，禁止重复触发。

### 9.3 打印（FILE-17）

- `Alt+Shift+P` 或菜单打开 WebView2 打印预览；打印目标是 §9.0 的专用打印视图，应用界面不出现在打印产物中；取消不影响正文与文件。
- 打印范围、纸张、页边距由打印预览控制；应用不修改系统默认打印机。
- 打印与导出不写入用户文档目录，除非用户选择的目标就是该目录。

## 10. 视图模式与窗口（M5-7）

### 10.1 专注模式（F8）

- 仅编辑模式可用；弱化当前段落以外的正文，当前段落保持正常对比度；再按 F8 或菜单退出。
- 阅读/预览模式禁用并说明“专注模式只在编辑模式可用”；每窗口独立。

### 10.2 打字机模式（F9）

- 仅编辑模式可用；输入或移动光标时把当前行保持在视口约 40% 高度，不改变其他窗口。
- 退出后恢复正常滚动；不影响打印与导出。

### 10.3 全屏与置顶

- `F11` 切换当前原生窗口全屏；退出恢复原窗口尺寸与位置。
- “保持窗口在最前端”为当前窗口复选菜单项，状态可见；关闭后恢复普通层级。
- 两者都是每窗口状态，不写入全局设置；窗口由 Go 绑定用 `mygo.CallerWindow(ctx)` 定位，不接受前端传入的窗口 ID。

### 10.4 缩放（VIEW-13/14/15）

- `Ctrl+Shift+=` 放大、`Ctrl+Shift+-` 缩小，步进 10%，范围 50%–200%；`Ctrl+Shift+9` 恢复 100%。
- 缩放只作用于当前窗口的整页 WebView2 缩放（含工具栏与状态栏，等价于浏览器缩放），不修改系统 DPI、不影响其他窗口。
- 视图菜单显示当前百分比；到达上下限时禁用对应方向并说明。窗口由 `mygo.CallerWindow(ctx)` 定位，不接受前端传入的窗口 ID。

### 10.5 应用内窗口切换（VIEW-16）

- `Ctrl+Tab` 按最近使用顺序激活下一个本应用窗口，`Ctrl+Shift+Tab` 反向；只在本应用窗口间循环，不新建窗口、不引入标签页。
- 最近使用顺序由 Go 侧窗口注册表维护：每次窗口获得焦点时更新 MRU 序列；没有记录时按创建顺序。
- 快捷键由页面 `keydown` 捕获；M5-7 必须实测 WebView2 是否把 `Ctrl+Tab` 当作系统焦点切换吞掉。若被吞掉，再评估原生菜单加速器转发或调整默认键，并把结论写入 `docs/decisions.md`；不得注册全局热键。
- 对话框打开时不切换；没有其他窗口时不动作。
- 切换后目标窗口获得焦点，当前文档与缓冲不变。

### 10.6 字数统计（VIEW-10）

- 菜单打开只读统计窗口；有选区时统计选区，否则统计全文。
- 统计口径：CJK 字符每字计 1 个词；连续拉丁字母/数字/下划线计 1 个词；显示字符数（含/不含空白）、词数、段落数。
- 排除 YAML front matter 与注释；代码块与公式源码计入字符，代码中的连续标识符按 1 个词计。源码选区包含注释时，注释内容不计入。
- 统计按解析后的正文口径；不修改文档、不写盘；大文档在 Go 或后台计算，不阻塞输入。

### 10.7 状态栏显隐（VIEW-09）

- 视图菜单提供“显示状态栏”复选项，选择写入设置并跨窗口生效、重启保留。
- 隐藏后仍通过标题 `•` 与提示消息暴露保存失败、冲突等关键状态，不丢失错误入口。
- 显示状态栏时保留现有编码、换行、大小、更新时间与窗口信息。
- P2 的设置页只新增“显示状态栏”偏好；左侧视图、缩放、专注/打字机/全屏/置顶为每窗口会话状态，不写入设置。

## 11. 主题菜单（M5-8）

- 顶层新增“主题”菜单，位于“视图”和“帮助”之间。
- 菜单项为浅色、深色、跟随系统三项单选，与设置中的外观选项共用同一状态与持久化；切换后所有窗口立即应用。
- P2 不新增主题、不提供自定义配色；PRD 16.2 的“更多内置主题”建议本期不实现，已在 §2 非目标注明。现有 DESIGN.md 两套令牌是唯一来源。

## 12. 菜单与快捷键

- 新增 P2 菜单项默认不给快捷键；PRD 已给出的保留：`Ctrl+U` 下划线、`F8` 专注、`F9` 打字机、`F11` 全屏、`Ctrl+Shift+1/2/3` 左侧视图、`Ctrl+Shift+F` 目录搜索、`Ctrl+Shift+9/=`/`-` 缩放、`Ctrl+Tab` 窗口切换、`Alt+Shift+P` 打印。
- `Ctrl+Shift+L` 继续显示/隐藏侧边栏，视图菜单补同一入口。
- `Ctrl+P` 仍是快速打开，不改为打印；`Ctrl+=`/`Ctrl+-` 仍是标题升降级，不改为缩放。
- 菜单、快捷键与工具栏调用同一命令与启用条件；禁用项显示原因。
- 没有列出默认快捷键的命令不进入页面 `keydown` 映射表，只通过菜单/工具栏调用；新增命令默认不注册按键处理。
- `Win+.` 不注册全局快捷键，只显示系统面板提示。

## 13. 安全与写入边界

- 新增渲染元素必须由 Go 渲染器生成；文档提供的原始 HTML 仍转义，唯一例外是精确的 `<u>`/`</u>`。
- 警告框类型、TOC 条目、脚注 id、类名都来自固定枚举或渲染器状态，不能由文档任意指定；警告框、TOC、脚注的白名单增量见 §3.2–§3.4。
- `class` 只允许闭合白名单；`data-type` 只允许五种警告类型；URL 协议仍只允许 http/https/mtres/相对路径/`#` 锚点。
- 导出 HTML 使用独立导出清理器：只接受渲染管线产物，MathML/SVG 只保留固定子集，`data:image` 只允许 `img.src`；导出模板样式是固定字符串。
- 目录搜索命中片段按纯文本渲染；打开命中文件仍经 pathguard 校验。
- 复制 HTML 与简化格式通过 `transfer.Data` 同时提供 HTML 与纯文本；不执行剪贴板 HTML。
- 复制 HTML 经过页面白名单清理；导出 HTML 经过独立导出清理器；两者都不执行脚本、不请求远程资源。
- P2 允许写用户文件的动作仅限：显式移动、移入回收站、图片复制/粘贴落盘、导出 HTML/PDF、打印到用户选择的目标。其余路径保持只读。
- 图片落盘先确认目标 `assets/` 路径；授权只覆盖本次写入的资源文件，不改变目录读取范围。
- 目录搜索只读已授权根；不跟随重解析点越界，不读取未授权路径。
- 图片复制、图片插入、属性读取都不访问网络。

## 14. 容量、错误与性能

- 表格插入行列上限 20×20；超大表格编辑只改当前行/列，不整表重排。
- 目录搜索上限 500 条命中、200 个文件；单文件 10 MiB；结果截断明确提示。
- 大纲与 TOC 最多 500 个标题；超出时截断并提示。
- 导出内嵌图片总量上限 20 MiB；PDF 生成超时 30 秒。
- 移动/删除/图片落盘失败都保留原文件与缓冲，显示原因，可重试；不产生半成品或静默永久删除。
- 所有新增命令的失败路径都有图标加文字提示，不只靠颜色。

## 17. 技术前置与风险

- 已验证 mygo v0.9.0 提供：`Page.PrintToPDF`、`Page.Print`、`Window.SetFullScreen/ToggleFullScreen`、`Window.SetAlwaysOnTop`、`Page.SetZoomFactor/ZoomFactor`、`Window.Focus`、`Windows()`、`Shell.TrashItem`、`Shell.ShowItemInFolder`、`Clipboard.ReadImage/WriteImage`、`Clipboard.Write(transfer.Data)`（HTML+文本双格式）。这些不需要升级 mygo。
- 新增打印样式是必做项：当前没有 `@media print`，M5-6 必须先补打印 CSS/独立打印文档，并用长文档、表格、公式、Mermaid 样本验收；不能假设现有页面可直接打印。
- 打印视图若用隐藏窗口加载导出 HTML，必须处理 CSP、图片路径（data URI 或重新注册 `mtres`）、DOM 加载完成与超时；M5-6 实测后记录方案与失败回退。
- 目录移动、跨盘复制校验、属性读取由项目 Go 代码实现；跨盘移动必须先校验再删除源文件。
- PDF 使用专用打印视图生成，必须验证阅读区完整输出、长表格分页与公式/图表不截断；如果 mygo 隐藏窗口或等价方案实测不满足，停在 M5-6 向用户报告，不改为“打印为 PDF”冒充直接导出。
- `Ctrl+Tab` 在 WebView2 中可能需要原生菜单加速器捕获；实现方式在 M5-7 实测后记录到 `docs/decisions.md`，不能引入全局热键。
- 图片复制/粘贴需要把 JPEG/GIF/WebP 转为 PNG：JPEG/GIF 用标准库，WebP 用 `golang.org/x/image/webp` 解码后再用 `image/png` 编码；新增依赖先记录到 `docs/decisions.md`。
- 警告框、TOC、脚注、下划线的渲染改动必须同步扩展 `internal/markdown` 的白名单与恶意样本集；任何新增元素或属性都要有闭合枚举/正则，不得放开 `.*` 类名。脚注白名单至少涉及 `sup`、`li[id]`、`div.footnotes`、`a.footnote-ref`、`a.footnote-backref`；TOC 涉及 `nav.toc`、`ol.toc-list`、`a.toc-link`；警告框涉及 `div.alert*`、`p.alert-title` 与 `data-type` 五值枚举。
- 警告框需要在 goldmark AST 上识别引用块首行标记并自绘渲染；TOC 需要先收集标题再回填占位；两者不能靠 bluemonday 放行文档 HTML 实现。
- HTML 导出需要前端在渲染结果上再生成独立文档：公式转 MathML、Mermaid 序列化 SVG、图片转 data URI；M5-6 必须先验证离线打开效果与 20 MiB 上限，再定稿导出模板。
- 目录搜索与大文档导出先做容量测试，再决定是否需要后台任务或进度提示；不把“未实测”写成“已达标”。

## 18. 与 P1 的边界变化

- P1 的“只有显式保存/另存为/保存全部才写文件”扩展为：显式移动、移入回收站、图片落盘、导出/打印目标文件也属于用户显式动作；其余路径仍只读。
- 左侧视图从“只有文件树”扩展为三种视图；当前文档与缓冲不因切换视图改变。
- 菜单从六个顶层扩展为七个（新增“主题”）；视图菜单新增 P2 命令。
- 预览新增表格（已有）、脚注、警告框、TOC、下划线、隐藏注释；原始 HTML 仍转义，唯一例外是无属性 `<u>`/`</u>`。
- 导出与打印复用同一渲染管线，不绕过白名单；导出的 HTML 不包含应用界面与脚本。
