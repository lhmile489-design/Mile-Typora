# Mile Typora

Windows 11 上的本地 Markdown 阅读与源码编辑器。P0 只读阅读与 P1 基础编辑已完成；P2 效率与高级排版已按阶段推进到 M5-6。当前支持源码编辑与预览、保存与未保存保护、常用段落命令。所有行为以 [docs/PRD.md](docs/PRD.md) 为准，P2 范围见 [docs/P2-效率与排版需求.md](docs/P2-效率与排版需求.md)。

## 功能

### 阅读（P0）

- 打开 `.md` / `.markdown`（大小写均可），单文件或目录文件树。
- 一个进程多个原生窗口；空白窗口就地打开，非空白窗口把新文件交给新窗口。
- CommonMark + GFM：标题、列表、表格、任务列表、引用、代码高亮、front matter。
- KaTeX 公式与 Mermaid 图表，按需加载、局部降级，失败不影响正文其余部分。
- 外部修改自动刷新（多窗口共享监听），删除或根目录消失时保留旧内容并标过期。
- 文内查找、阅读位置恢复、最近打开、启动恢复、浅色 / 深色 / 跟随系统。
- 本地图片经应用内 `mtres` 协议按文件头与容量校验后提供。
- 不发起远程请求；外部链接确认后交系统浏览器。

### 编辑（P1，已完成）

- `Ctrl+/` 在源码编辑与预览之间切换，同一缓冲。
- 新建、保存、另存为；关闭、切换文件或退出前处理未保存修改；保存冲突不静默覆盖。
- 撤销 / 重做、剪切复制粘贴、粘贴为纯文本、复制为 Markdown。
- 标题、段落、引用、公式块、代码块、有序 / 无序 / 任务列表等段落命令。
- 加粗、斜体、行内代码、删除线、链接与清除样式。
- 当前行/段落选择、上下移动行、向前删除；源码编辑查找与替换（单次 / 全部，各一步撤销）。
- 文件 / 编辑 / 段落 / 格式 / 视图 / 帮助菜单，菜单、工具栏与快捷键调用同一命令；保存全部逐窗口汇总。
- 编辑时外部修改或删除会提示：重新载入（需确认）/ 另存为 / 保留当前编辑；多窗口保存冲突不静默覆盖。
- 除显式保存、另存为外不写用户文件；P0 的阅读路径仍保持只读。

### 文件与视图（P2 M5-1/M5-2/M5-3/M5-4/M5-5/M5-6）

- 文件菜单新增移动到…、属性…、打开文件位置…、在侧边栏中显示、删除…；删除只移入回收站。
- 移动到目标目录前处理未保存修改；目标重名不覆盖；跨盘移动复制校验后才删除源文件。
- 属性只读展示路径、大小、编码、换行、修改时间与只读属性；混合换行显示“混合”。
- 左侧支持文件树、文档列表、大纲和目录搜索；`Ctrl+Shift+1/2/3` 切换视图，`Ctrl+Shift+F` 搜索当前目录。
- 大纲点击定位标题；文档列表重名显示相对路径；目录搜索按文件名与正文匹配，可取消并显示截断提示。
- 段落菜单支持表格插入与行列/对齐、五种警告框、脚注、链接引用、内容目录、文档元信息；格式菜单支持下划线 `Ctrl+U` 与注释。
- 阅读支持脚注、警告框、`[TOC]`、下划线与隐藏注释；原始 HTML 仍转义，警告框/TOC/脚注结构由渲染器生成。
- 格式菜单的链接操作子菜单支持编辑地址、移除链接、复制链接地址；行内与引用式链接分别处理。
- 格式菜单支持插入图片与更换图片：本地 PNG/JPEG/GIF/WebP 确认后复制到文档同目录 `assets/`，重名自动加序号，不覆盖已有文件。
- 编辑菜单支持拷贝图片：编辑器图片语法或阅读区选中的本地图片统一转 PNG 写入剪贴板。
- 支持复制为纯文本、复制为 HTML 代码、复制内容并简化格式；HTML 与纯文本回退写入同一个剪贴板 Item，源码与阅读选区都能使用。
- 编辑区 `Ctrl+V` 文本优先；剪贴板只有图片时进入图片粘贴确认，图片转 PNG 存到文档 `assets/`。
- 文件菜单支持导出 HTML 与 PDF：HTML 为单文件（MathML、内联 Mermaid SVG、data URI 图片），PDF 通过独立打印视图生成；`Alt+Shift+P` 在独立视图打开打印预览。

## 运行要求

- Windows 11 x64。
- Microsoft Edge WebView2 Runtime。缺失时应用启动会提示安装地址，不会停在白屏。
- 不需要管理员权限即可阅读；安装包由 mygo 的 NSIS 向导生成。

## 安装与启动

- 安装包：`build/windows-amd64/mile-typora-setup-<版本>-amd64.exe`。
- 免安装运行：`build/windows-amd64/Mile Typora.exe`。
- 首次启动是空白页；可在“设置 → 常规 → 启动时”选择恢复上一份文档或打开空白页。

应用数据保存在 `%APPDATA%\Mile Typora\settings.json`（最近记录、启动与外观偏好、恢复目标），不会写入文档目录。

## 从源码构建

需要 Go 1.27.3、Bun 1.3、WebView2 Runtime。

```bash
bun install
bun run generate        # 生成 src/mygo.ts（改绑定后）
bun run dev             # 开发窗口 + Vite（5273）
bun run build           # 正式包与安装包，产物在 build/
```

验证：

```bash
go vet ./...
go test ./...
go test -run '^$' -bench . -benchmem ./internal/scan ./internal/markdown
bun run typecheck
bunx vitest run
bun run build:web
```

`go test -race` 在本机因缺少 gcc 不可用（decisions.md D-T14）；并发正确性用专项测试覆盖。

## P0 边界

- 不编辑、不保存、不新建文档；右侧预留栏只占位。
- 不支持导航到不支持的类型或外部页面；PDF、图片查看器等不在范围内。
- 大目录（超过扫描边界）会提示结果不完整；超出目录监听上限时用 `F5` 手动刷新。
- 远程图片不加载；本地图片格式限 PNG / JPEG / GIF / WebP。
